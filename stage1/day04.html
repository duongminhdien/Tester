二、HTML 骨架结构
01 — 标签分类
单标签
<标签名 />
自闭合，无内容
例：<br /> <img />
双标签
<标签名></标签名>
有开始有结束
例：<p></p>
属性
属性名="属性值"
描述标签特征
例：href="url"
02 — 完整骨架结构
<!-- 声明文档类型 --> <!DOCTYPE html> <html> <!-- 根标签，所有内容放这里 --> <head> <!-- 头部标签，配置信息 --> <meta charset="UTF-8"> <!-- 字符编码 --> <title>传智播客黑马程序员</title> <!-- 页面标题 --> </head> <body> <!-- 身体标签，代码编写区域 --> <!-- 这里写页面内容 --> </body> </html>
💡 注释测试点（面试高频）：前端页面上线之前，测试人员需要检查注释——注释中可能包含敏感信息（密码、内部接口地址、开发调试信息），必须在上线前清除！快捷键：Ctrl+/
三、常见 HTML 标签 & 测试点
<h1> ~ <h6> 标题标签
h1最大，h6最小。独占一行，具有语义化特征。
<h1>我是h1</h1>
<h6>我是h6</h6>
标题层级是否正确，SEO 相关
<p> 段落标签
语义化，独占一行（块元素），前后自动留空行。
<p>我是段落</p>
文本是否正确显示，段落间距
<a> 超链接标签
点击文本跳转到指定页面。href=跳转地址；target=打开方式（_blank新窗口）。
<a href="https://..." target="_blank">
点击跳转
</a>
链接是否有效、target是否正确、点击区域是否合理
<img> 图片标签（单标签）
src=图片路径；title=悬停文字；alt=未加载时提示；width/height=尺寸。
<img src="pic.jpg" title="悬停文字"
alt="未加载提示" width="100"/>
必须有 title 属性；alt 图片未加载时显示；图片路径正确
<div> / <span> 布局标签
div：大盒子，独占一行（块元素）
span：小盒子，一行可放多个（行内元素）
<div>独占一行</div>
<span>内联1</span><span>内联2</span>
页面布局是否正确，响应式适配
<ul>/<ol> 列表标签
ul=无序列表（●）；ol=有序列表（1.2.3.）；li=列表项
<ul><li>测试</li><li>开发</li></ul>
列表项数量、排序是否正确
<br> / &nbsp; 换行与空格
br=换行（单标签）；&nbsp;=空格字符实体（& + shift+7）
黑马<br />软件&nbsp;&nbsp;测试
换行位置是否符合设计，间距是否统一
<script>/<style>/<link>
script=引入JS；style=内联CSS；link=外部CSS文件
<script>// JS代码</script>
<link rel="stylesheet" href="s.css">
资源是否正常加载，是否存在死链
四、表单元素（Input & Form）— 测试核心
03 — Input 标签类型（测试重点）
type值元素类型示例代码测试点
text文本框<input type="text">输入内容、最大长度、特殊字符
password密码框<input type="password">是否加密显示（●●●）、强度验证
radio单选按钮<input type="radio" name="one">同组（同name）只能选一个、默认值
checkbox复选框<input type="checkbox">多选、全选、反选功能
submit提交按钮<input type="submit">提交表单数据，value属性改按钮文字
reset重置按钮<input type="reset">恢复所有字段为默认值
button普通按钮<input type="button" value="点我">默认无执行效果，需配合JS；value赋值
🔴 单选按钮测试要点：必须给同一组的 radio 设置相同的 name 属性值，才能实现单选效果。如果 name 不同，每个都可以独立选中，这是 Bug！
⚠️ 按钮测试要点：普通按钮（type=button）默认没有任何执行效果，需要配合 JS 实现。统一使用 value 属性来设置按钮显示文字。
04 — Form 标签 & GET vs POST（核心考点）
form 标签的作用：将页面输入的数据提交到后台或指定页面。
关键属性：action（提交到哪个地址）+ method（提交方式 get/post）
🔵 GET 方法
📌参数在 URL 中明文显示（可见）
⚡提交速度较快
📏参数长度有限制（约2KB）
🔍适合：查询操作（搜索、分页）
?username=admin&password=123
🟡 POST 方法
🔒参数在 请求体中，URL 不可见
🐢提交速度相对较慢
∞参数长度无限制
✍️适合：登录、注册、提交数据
请求体中：{username:admin, password:123}
🔴 高频面试题：GET 和 POST 的区别？
① GET 参数 URL 明文可见，POST 在请求体不可见
② GET 有长度限制，POST 无限制
③ GET 用于查询，POST 用于提交数据（登录/注册）
④ GET 速度快（无请求体），POST 慢（需处理请求体）
⑤ 安全性：POST 更安全（密码不在URL暴露）

登录页面需求说明（来自 Day04 课堂）
1. 输入手机号（11位中国手机号）：
文本框失去焦点时验证，红色=失败，绿色=成功

2. 点击发送验证码：
手机号绿色→弹出"点击按钮进行验证"；手机号红色→提示不正确

3. 点击按钮进行验证（拖拽验证）：
拖拽图形到指定位置→按钮消失；未到位→晃动提醒，回到原位；超过5次→提示"尝试过多"

4. 输入验证码：
正确验证码 + 勾选协议 → 登录进入系统
错误验证码 + 勾选协议 → 提示验证码错误
正确验证码 + 未勾选协议 → 提示请勾选

5. 点击登录：手机号、验证码均绿色，勾选协议 → 登录成功
