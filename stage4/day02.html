1if 判断语句

判断语句的作用：根据条件的真假，决定执行哪段代码。对应自然语言中的"如果……否则……"。

单独 if 语句

语法格式
if 判断条件: # 条件成立，执行这里的代码块 执行的代码 执行的代码 # 这行与 if 无关（不在缩进中）
📌 语法要点：
1. if 后边需要一个 冒号 :
2. 冒号之后回车并缩进（PyCharm 会自动添加）
3. 缩进中的代码称为 代码块，要么都执行，要么都不执行
4. 与 if 无关的代码不需要写在缩进中
# 示例：判断是否满18岁 age = int(input('请输入年龄:')) if age >= 18: print('满18岁，可以进入网吧') print('这行和if无关，无论如何都会执行')

if else 结构

语法格式
if 判断条件: # 条件成立执行 执行的代码 else: # 条件不成立执行 执行的代码
⚠️ 注意：else 不能单独使用，必须与 if 配合，且必须对齐。if 和 else 之间不能有顶格书写的代码。
# 示例：是否满18岁 age = int(input('请输入年龄:')) if age >= 18: print('可以进网吧嗨皮') else: print('回家写作业！')

if elif else 结构（多分支）

语法格式
if 判断条件1: 条件1成立执行 elif 判断条件2: # 条件1不成立才判断 条件2成立执行 elif 判断条件3: 条件3成立执行 else: 以上都不成立才执行
💡 核心规则：一旦某个条件成立，后续的 elif/else 全部跳过，不再判断。利用这个特性可以简化条件写法：已知 score < 90 时，elif score >= 80 就等价于 80 <= score < 90。
# 示例：成绩等级判断（简化写法） score = int(input('请输入分数:')) if score >= 90: print('优') elif score >= 80: # 隐含 score < 90 print('良') elif score >= 70: print('中') elif score >= 60: print('差') else: print('不及格')

if 嵌套

当判断条件存在 递进关系（第一个条件成立，才有必要判断第二个条件）时，使用 if 嵌套。

语法格式

# 案例：ATM取款机 — 先验证密码，再判断余额 pwd = input('请输入密码:') if pwd == '123456': print('密码正确') money = int(input('请输入取款金额:')) if money > 1000: print('余额不足') else: print('取款中，请稍后...') else: print('密码错误，请重试') # 案例：先验证码 → 再验证用户名密码 code = input('请输入验证码:') if code == '8888': username = input('请输入用户名:') password = input('请输入密码:') if username == 'admin' and password == '123456': print('登录成功') else: print('用户名或密码错误') else: print('验证码不正确，请重新输入')

3while 循环

循环的作用：让指定的代码 重复执行。while 适合"不知道确切次数，满足条件就执行"的场景。

基本语法
# 1. 定义计数器（循环初始条件） i = 0 # 2. 循环判断条件 while i < 5: # 循环体（重复执行的代码） print('我错了...') # 3. 计数器 +1（避免死循环） i = i + 1
🔁 执行顺序：初始条件 → 判断 → 循环体 → 计数器+1 → 判断 → 循环体 → ... → 条件不成立 → 结束

死循环 vs 无限循环

❌ 死循环（Bug）

程序员不小心造成，忘记更新计数器，导致无法退出。

i = 0 while i < 5: print('永远执行') # ❌ 忘记写 i += 1
✅ 无限循环（刻意设计）

故意用 while True，内部用 break 在满足条件时退出。

while True: 用户输入... if 满足退出条件: break # 终止循环

break 与 continue

关键字作用使用范围
break立即终止整个循环只能在循环中使用
continue结束本次循环，继续下一次只能在循环中使用
# 求 1-100 的累加和 i = 1 num = 0 while i <= 100: num = num + i # 0+1+2+...+100 i += 1 print('求和结果为:', num) # 5050 # 登录系统 + while 无限循环 + break while True: username = input('请输入用户名:') if username == 'exit': break password = input('请输入密码:') if username == 'admin' and password == '123456': print('登录成功') break else: print('用户名或密码错误！请再次输入')

4for 循环

for 循环也称 for 遍历，用于从容器（字符串/列表/元组/字典）中逐个取出数据，也可做指定次数的循环。

遍历字符串

for 变量 in 字符串: 重复执行的代码 # 示例：逐个打印字符 str1 = 'abcd' for i in str1: print('字符:', i) # 输出: a b c d

指定次数循环

for 变量 in range(n): 重复执行的代码 # range(5) → [0,1,2,3,4] for i in range(5): print('第', i, '次')
💡 range() 说明：range(n) 生成 [0, n) 的整数序列，不包含 n。求1-100的和用 range(101)（包含100）。
# for 循环求 1-100 的累加和 num = 0 for i in range(101): # range(101) → 0,1,2,...,100 num += i print('求和结果为:', num) # 5050

Q1
if、if-else、if-elif-else 三者有什么区别？分别适用什么场景？
基础
+

if（单独）：只有条件成立时才执行，条件不成立直接跳过。适用于"只在满足条件时做某事"的场景。

if-else：二选一，条件成立走 if 块，否则走 else 块，必定执行其中之一。

if-elif-else：多分支，按顺序判断，第一个成立的条件执行后，其余全部跳过。适合多个互斥条件（成绩等级、年龄阶段等）。

💡 记忆口诀：单 if = 可选执行；if-else = 必选其一；elif = 多选一。
Q2
Python 中缩进有什么作用？缩进错误会导致什么问题？
基础
+

Python 使用 缩进（4个空格或1个Tab）来表示代码块，替代其他语言中的大括号 {}。

属于同一代码块的语句必须有相同的缩进级别。缩进错误会导致 IndentationError 或逻辑错误（代码不在期望的块中执行）。

⚠️ 常见错误：混用空格和Tab导致的 TabError，建议统一使用4个空格（PyCharm 默认）。
Q3
and、or、not 逻辑运算符的运算规则是什么？有短路求值吗？
基础
+

and：两侧都为 True 才返回 True。存在"短路"——左边为 False 时，右边不再求值。

or：一侧为 True 即返回 True。"短路"——左边为 True 时，右边不再求值。

not：取反，not True → False，not False → True。

短路求值意义：可以利用短路避免异常，如 if x != 0 and 10/x > 1，x 为 0 时不会执行除法。
Q4
if 嵌套和 if-elif 有什么区别？什么时候用嵌套？
进阶
+

if-elif：条件之间是 并列关系，不分先后，满足哪个就执行哪个。

if 嵌套：条件之间是 递进关系，只有外层条件成立，才有必要判断内层条件。

典型场景：ATM先验密码才能取款；登录先验验证码才验用户名密码。

💡 判断依据：第二个条件只有在第一个条件成立时才有意义 → 用嵌套。两个条件互相独立 → 用 elif。
Q5
while 循环和 for 循环有什么区别？各自适用什么场景？
基础
+

while 循环：适合不确定循环次数的场景。只要条件成立就持续执行，需要手动维护计数器。例如：用户登录重试、猜数字游戏。

for 循环：适合已知次数或遍历容器的场景。自动从容器中逐个取出数据，或配合 range() 做固定次数循环。例如：遍历字符串、1-100累加。

Q6
break 和 continue 有什么区别？只能用在哪里？
基础
+

break：立即终止 整个循环，循环后续代码不再执行，直接跳到循环结束后的第一行代码。

continue：结束 本次循环 的剩余代码，回到循环开头判断条件，继续下一次循环。

两者都只能用在循环（while / for）中，不能单独使用。

⚠️ 常见陷阱：在 while True 中使用 continue 时，要确保计数器在 continue 之前已更新，否则可能造成死循环！
Q7
range() 函数的用法是什么？range(5)、range(1,6)、range(0,10,2) 分别生成什么？
进阶
+

range(stop)：生成 [0, stop) 的整数序列。
range(start, stop)：生成 [start, stop) 的整数序列。
range(start, stop, step)：带步长的序列。

写法生成序列
range(5)0, 1, 2, 3, 4（不含5）
range(1, 6)1, 2, 3, 4, 5（不含6）
range(0, 10, 2)0, 2, 4, 6, 8（步长2）
range(101)0-100（含100，用于1-100累加）
Q8
死循环和无限循环有什么区别？无限循环在实际开发中有什么用途？
进阶
+

死循环（Bug）：因为开发者失误（忘记更新计数器等）造成的无法退出的循环，属于程序错误。

无限循环（刻意设计）：使用 while True: 有意让程序持续运行，内部通过 break 或特定条件退出。

实际用途：用户登录重试、服务器监听请求、游戏主循环、菜单系统等需要持续运行直到用户主动退出的场景。

Q10
random.randint(1, 10) 和 random.randint(0, 9) 有什么区别？
进阶
+

random.randint(a, b) 生成 [a, b] 之间的随机整数，包含 a 和 b 两端。

randint(1, 10)：可能生成 1, 2, 3, ..., 10（共10个数）

randint(0, 9)：可能生成 0, 1, 2, ..., 9（共10个数）

两者范围不同，但数量相同。注意区别于 range(1, 10)（不含10）。

Q11
下面代码有什么问题？如何修复？
陷阱题
+
i = 0 while i < 5: if i == 3: continue print(i) i += 1

问题：当 i == 3 时执行 continue，跳过了 i += 1，导致 i 永远等于3，形成 死循环！

修复方案：将 i += 1 放在 continue 之前：

i = 0 while i < 5: i += 1 # ✅ 先更新计数器 if i == 3: continue print(i)

+

1以下关于 if 语句的描述，错误的是？
A. if 后面必须有冒号
B. if 代码块必须缩进
C. else 可以单独使用，不需要配合 if
D. if 和 else 之间不能有顶格书写的代码
解析：C 错误。else 不能单独使用，必须配合 if（或 for/while），且必须与 if 对齐。
2下列代码的输出结果是什么？
score = 85; print('优') if score>=90 else print('良') if score>=80 else print('中')
A. 优
B. 良
C. 中
D. 不及格
解析：score=85，不满足 >=90，满足 >=80，输出"良"。这是 Python 三元表达式（条件表达式）的链式写法。
3if-elif-else 结构中，如果第一个 elif 的条件成立，以下描述正确的是？
A. 继续判断后续所有 elif 条件
B. 执行该 elif 块后，跳过其余 elif 和 else
C. 还会执行 else 块
D. 程序报错
解析：if-elif-else 结构：一旦某个条件成立，执行对应块后，后续所有分支（elif/else）全部跳过，不再判断。
4以下代码执行后，输出的是什么？
i=0; [print(i) or i.__setattr__('x',0) for _ in range(3)] — 简化版：i=5，while i>0: i-=2，循环结束时 i 等于？
A. 0
B. 1
C. -1
D. 2
解析：i=5 → 3 → 1 → -1，当 i=-1 时不满足 i>0，循环退出，此时 i=-1。
5random.randint(1, 100) 可能生成的最大值和最小值分别是？
A. 最大99，最小1
B. 最大100，最小1
C. 最大100，最小0
D. 最大99，最小0
解析：randint(a, b) 生成 [a, b] 的整数，包含两端。所以最小值=1，最大值=100。
6range(1, 10, 3) 生成的序列是？
A. [1, 4, 7, 10]
B. [1, 4, 7]
C. [1, 3, 6, 9]
D. [0, 3, 6, 9]
解析：range(1, 10, 3) 从1开始，步长3，不超过10：1, 4, 7（10不含）。
7以下关于 break 和 continue 的描述，正确的是？
A. break 结束本次循环，continue 终止整个循环
B. continue 结束本次循环，break 终止整个循环
C. 两者都可以终止整个循环
D. 两者都只是跳过本次循环
解析：B 正确。continue：结束本次循环，继续下次。break：直接终止整个循环，不再执行循环体。
8以下代码会输出几次"hello"？
for i in range(5):
    if i == 3: break
    print('hello')
A. 5次
B. 4次
C. 3次
D. 0次
解析：i=0,1,2 时打印 hello（3次），i=3 时执行 break 退出循环，不打印。所以共输出3次。
9闰年的判断条件是什么？以下哪个年份是闰年？
A. 1900（能被100整除）
B. 2100（能被100整除）
C. 2000（能被400整除）
D. 2023（不能被4整除）
解析：闰年：①能被4整除且不能被100整除，或②能被400整除。2000能被400整除 → 闰年✅。1900/2100能被100整除但不能被400整除 → 非闰年❌。
10下面代码中，pass 语句的作用是？
A. 跳过当前循环
B. 终止程序
C. 占位符，什么也不做，保持代码语法完整
D. 等同于 continue
解析：pass 是空语句/占位符，语法上需要代码块但暂时没有内容时使用，什么也不做，避免语法错误。
11以下哪种情况会导致死循环？
A. while True: 内有 break 语句
B. while i < 5: 内忘记写 i += 1
C. for i in range(100): 循环100次
D. while i < 0: i 初始值为5
解析：B 会死循环：i 的初始值小于5，条件始终成立，且没有更新 i，无法退出。D 不会死循环（初始就不满足条件）。
12for i in 'hello': 会循环几次？
A. 1次
B. 4次
C. 5次
D. 6次
解析：'hello' 有5个字符：h/e/l/l/o，for 循环会逐个取出每个字符，共循环5次。
13以下代码的输出是？
x = 10; print('A') if x > 5 and x < 20 else print('B')
A. A
B. B
C. AB
D. 报错
解析：x=10，10>5 为 True，10<20 为 True，and 两边都为 True → 条件成立 → 输出 A。
14Debug 时，在 PyCharm 中单步执行的快捷键是？
A. F5
B. F7
C. F8
D. F10
解析：PyCharm 中 F8 是"Step Over"（单步执行，不进入函数内部），是 Debug 时最常用的按键。F7 是 Step Into（进入函数）。
15猜数字游戏中，使用 while True + break 的原因是什么？
A. 为了让程序运行更快
B. 因为不知道用户需要猜几次才能猜中，用无限循环+猜中时break最合适
C. while True 是 Python 的语法要求
D. 使用 for 循环无法实现猜数字
解析：猜数字不知道用户需要猜多少次，while True 让程序持续运行，猜中时 break 退出，这正是"不确定次数循环"的最佳场景。
