1字符串 str

字符串是用 引号（单引号、双引号、三引号）引起来的内容，属于 Python 的数据容器之一。

3元组 tuple & 组包/拆包

元组用 () 定义，与列表非常相似，最大区别是 元组中的数据不能修改，主要用于传参和返回值。

# 定义元组 tuple1 = () # 空元组 tuple2 = (1, 2, 'hello') # 非空元组 tuple3 = (10,) # 单元素元组，逗号必须有！ tuple4 = tuple([1,2,3]) # 列表转元组 print(tuple2[2]) # hello（支持下标） # tuple2[0] = 99 # ❌ 报错！元组不可修改
# 组包（pack）：多个值 → 元组 a = 1, 2 # a = (1, 2) # 拆包（unpack）：元组 → 多个变量 x, y = a # x=1, y=2 # 经典应用：交换两个变量的值 a = 10 b = 20 a, b = b, a # a=20, b=10 print(a, b) # 字符串拆包 x, y, z = 'abc' print(y) # b
⚠️ 单元素元组陷阱：(10) 是整数，(10,) 才是元组。定义单元素元组时，数据后面的逗号不能省略！

4字典 dict

字典用 {} 定义，由 键值对（key: value） 组成。字典的键不能重复，主要使用字符串类型。字典 没有下标，通过键访问值。

# 定义字典 my_dict = {'name': '小明', 'age': 18, 'height': 1.78} # ——— 增加/修改 ——— my_dict['age'] = 20 # 键存在 → 修改 my_dict['weight'] = 65 # 键不存在 → 添加 # ——— 删除 ——— my_dict.pop('height') # 根据键删除键值对 # ——— 查询 ——— print(my_dict['name']) # 小明（键不存在会报错） print(my_dict.get('sex')) # None（键不存在返回None，不报错） # ——— 遍历（三种方式）——— for k in my_dict: # 遍历键 print(k) for v in my_dict.values(): # 遍历值（最常用） print(v) for k, v in my_dict.items(): # 遍历键值对 print(k, v)

🔑 字典遍历三种方式对比

① 遍历键
for k in my_dict: print(k) # name age sex

适合：只需要键名

② 遍历值 ⭐最常用
for v in my_dict.values(): print(v) # 小明 18 男

适合：批量处理值

③ 遍历键值对
for k,v in my_dict.items(): print(k, v) # name 小明 # age 18

适合：同时需要键和值

Q1
Python 的四大数据容器（str/list/tuple/dict）各有什么特点？如何选择？
基础
+

str（字符串）：不可修改，存储文本，支持下标/切片。

list（列表）：可修改，有序，可存任意类型，支持下标/切片，最灵活。

tuple（元组）：不可修改，有序，主要用于函数传参和返回值，保护数据不被篡改。

dict（字典）：键值对，通过键快速查找值，键不重复，无下标。适合描述有属性的对象。

💡 选择原则：需要修改 → list；键值对映射 → dict；保护数据 → tuple；文本处理 → str。
Q2
字符串的 find() 和列表的 index() 有什么区别？
基础
+

find()：字符串专有，未找到返回 -1，不报错。字符串也有 index() 方法，但未找到会报错。

index()：字符串和列表都有，未找到直接报错（ValueError）。

列表没有 find() 方法，只有 index()。所以操作列表时要先判断是否存在，再用 index()。

⚠️ 记住：列表没有 find()。字符串两者都有，但 find() 更安全（不报错）。
Q3
切片语法 [start:end:step] 中，end 能取到吗？有哪些省略规则？
基础
+

end 取不到（左闭右开区间）。例如 'abcdefg'[0:3] 取下标0,1,2的字符，不含3。

省略规则：步长为1可省略 → [0:3:1] 等同 [0:3]；start为0可省略 → [:3]；取到末尾end可省略 → [4:]；全部省略 [:] 等于复制整个容器；步长为-1可逆序 → [::-1]。

Q4
字符串的 replace() 和 split() 方法会修改原字符串吗？
基础
+

不会修改原字符串。Python 的字符串是不可变类型（immutable），所有字符串方法都返回一个新的字符串，原字符串保持不变。

使用时需要用变量接收返回值：new_str = my_str.replace('a', 'b')，否则结果丢失。

Q5
列表的 pop() 和 remove() 有什么区别？
进阶
+

pop(index)：按 下标 删除，返回被删除的数据。不传参数时默认删除最后一个。

remove(data)：按 值 删除，删除第一个匹配的元素，返回 None。如果值不存在会报错。

Q6
列表的 sort() 和切片 [::-1] 都能排序/反转，有什么区别？
进阶
+

sort() 和 reverse()：直接修改原列表，原地操作，不返回新列表（返回None）。

切片 [::-1]：返回新列表，原列表不变。字符串 只能 用切片逆序（字符串没有 reverse() 方法）。

记忆：列表两种方式都能逆序；字符串只能切片逆序；sort()只能用于列表。
Q7
字典的 dict['key'] 和 dict.get('key') 有什么区别？实际开发中用哪个？
基础
+

dict['key']：键不存在时直接 报错（KeyError），适合确定键存在的情况。

dict.get('key')：键不存在时返回 None（不报错），更安全。还可以设置默认值：dict.get('key', '默认值')。

实际开发中推荐优先使用 get()，避免因键不存在而崩溃。

Q8
字典的键可以是什么类型？值可以是什么类型？键可以重复吗？
基础
+

键：必须是 不可变类型（字符串、数字、元组都可以）。键不能重复，后赋值的会覆盖前面的。

值：可以是任意类型（字符串、数字、列表、字典、函数等），没有限制。

⚠️ 列表不能作为字典的键（列表是可变类型），会报 TypeError。
Q9
元组和列表最大的区别是什么？元组在什么场景下使用？
基础
+

最大区别：元组的数据 不可修改，列表可以修改。

元组的使用场景：
① 函数返回多个值时（自动打包成元组）
② 作为字典的键（因为可哈希）
③ 需要保护数据不被意外修改时
④ 函数传参（不希望函数内部修改参数）

Q10
什么是组包（pack）和拆包（unpack）？有哪些实际应用？
进阶
+

组包：将多个值自动组成元组。a = 1, 2 → a 是元组 (1, 2)。

拆包：将容器中的多个值分别赋给多个变量。变量数量必须与容器元素数量相同。

实际应用：
① 交换变量：a, b = b, a
② 解包字符串：x, y, z = 'abc'
③ 函数返回多值：x, y = func()
④ for 循环解包：for k, v in dict.items()

Q11
join() 方法的作用是什么？使用时有什么注意点？
进阶
+

作用：将列表（或其他可迭代对象）中的元素用指定的分隔符连接成一个字符串。

语法：分隔符.join(列表)，注意是 分隔符调用 join，而不是列表调用。

⚠️ 注意：列表中的每个元素 必须是字符串类型，否则会报 TypeError。数字列表需先转换：[str(i) for i in nums]。
Q12
如何理解 Python 字符串的"不可变性"？这在实际代码中有什么影响？
陷阱题
+

字符串创建后，其内容 不能被修改。s[0] = 'X' 会报 TypeError。

replace()、split()、upper() 等方法都不改变原字符串，而是 返回新字符串。

s = 'hello' s.upper() # ❌ 结果丢失！ print(s) # hello（原字符串未变） s = s.upper() # ✅ 必须用变量接收 print(s) # HELLO
⚠️ 常见错误：调用字符串方法后不接收返回值，以为已修改了字符串。记住：字符串方法永远返回新字符串。

1'abcdefg'[-1] 的结果是？
A. a
B. f
C. g
D. 报错
解析：-1 表示最后一个元素，'abcdefg' 的最后一个字符是 g。
2'abcdefg'[::2] 的结果是？
A. abcd
B. aceg
C. bdfg
D. gfedcba
解析：[::2] 步长为2，从下标0开始：0→a, 2→c, 4→e, 6→g，结果是 aceg。
3'hello'.find('xyz') 的返回值是？
A. None
B. False
C. -1
D. 抛出异常
解析：find() 找不到时返回 -1，不报错。这是 find() 与 index() 最大的区别。
4执行 s = 'good'; s.replace('good','GOOD'); print(s) 输出的是？
A. GOOD
B. good
C. Good
D. 报错
解析：字符串不可变，replace() 返回新字符串，原字符串 s 未改变，所以仍然输出 'good'。
5'a-b-c'.split('-') 的结果是？
A. 'abc'
B. ['a', 'b', 'c']
C. ('a', 'b', 'c')
D. {'a','b','c'}
解析：split() 按指定字符分割，返回 列表，所以结果是 ['a', 'b', 'c']。
6以下关于列表的 append() 方法，正确的是？
A. 返回新列表，原列表不变
B. 直接修改原列表，返回 None
C. 在列表开头插入数据
D. 可以同时追加多个数据
解析：append() 直接在原列表末尾追加数据，返回 None，不生成新列表。在开头插入用 insert(0, data)。
7执行 t = (10)，t 的类型是？
A. tuple
B. list
C. int
D. str
解析：(10) 等同于 10，是整数。单元素元组必须写成 (10,)，逗号不能省略！
8以下哪个操作会导致报错？
A. d = {}; print(d.get('key'))
B. d = {'a':1}; print(d['a'])
C. d = {}; print(d['key'])
D. d = {}; d['new'] = 1
解析：C 会报 KeyError：键 'key' 不存在。A 用 get() 返回 None 不报错；B 键存在正常访问；D 是添加新键值对。
9字典中同一个键被定义两次，最终保留哪个值？
A. 第一次的值
B. 第二次的值（后者覆盖前者）
C. 两个值都保留
D. 报错
解析：字典的键唯一，后赋值的会覆盖前面的：{'a':1, 'a':2} 结果是 {'a':2}。
10以下哪种方式不能遍历字典中的所有值？
A. for v in d.values()
B. for k,v in d.items()
C. for k in d: print(d[k])
D. for v in d
解析：D 中 for v in d 遍历的是字典的 键，不是值。A/B/C 都能获取到值。
11','.join([1, 2, 3]) 会发生什么？
A. 输出 '1,2,3'
B. 输出 [1,2,3]
C. 报错（TypeError）
D. 输出 '123'
解析：join() 要求列表元素必须是字符串，[1,2,3] 是整数列表，会报 TypeError。正确写法：','.join(['1','2','3'])。
12以下哪种方式可以安全地逆序字符串 s？
A. s.reverse()
B. s[::-1]
C. s.sort()
D. reverse(s)
解析：字符串没有 reverse() 方法，也没有 sort()。只能用切片 [::-1] 逆序字符串。
13执行以下代码后，student_list[0] 的结果是什么？
lst = [['张三','18'],['李四','20']]; lst[0].append('男'); lst[0].pop()
A. ['张三','18','男']
B. ['张三','18']
C. ['李四','20']
D. 报错
解析：先 append('男') → ['张三','18','男']，再 pop() 删最后一个 → ['张三','18']。回到原始状态。
14以下关于字典 pop() 和列表 pop() 的区别，正确的是？
A. 两者都按下标删除
B. 字典 pop() 按键删除，列表 pop() 按下标删除
C. 两者都按值删除
D. 字典没有 pop() 方法
解析：字典 dict.pop('key') 按键删除键值对；列表 list.pop(index) 按下标删除，默认删最后一个。
15以下哪种方式可以将测试数据 {'username':'admin','password':'123'} 中的所有键值对打印出来？
A. for i in data: print(i, data[i])
B. for k,v in data.items(): print(k,v)
C. 以上两种都可以
D. 以上两种都不可以
解析：A 遍历键再用 data[i] 取值，C 直接用 items() 解包键值对，两种方式都能打印所有键值对。
