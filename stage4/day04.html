1in 操作符 & 集合 set

in 操作符

in 是 Python 关键字，用于判断容器中是否包含某个数据，返回 True 或 False。对字典使用时，判断的是 键 是否存在。

# 语法：数据 in 容器 print('a' in 'abcd') # True print(3 in [1, 2, 3]) # True print('x' in ['a', 'b']) # False print('name' in {'name': '小明'}) # True（字典判断键） # not in：判断不包含 print('z' not in 'abcd') # True

集合 set（了解）

集合用 {数据, 数据, ...} 表示，数据不能重复。最常见用途：对列表进行 去重。

my_list = [1, 2, 1, 2, 5, 2, 4, 13] # 方式一：list → set → list（去重，但顺序不保证） list1 = list(set(my_list)) print(list1) # [1, 2, 4, 5, 13]（顺序不固定） # 方式二：手动去重（保持原顺序） new_list = [] for i in my_list: if i not in new_list: # 不存在才添加 new_list.append(i) print(new_list) # [1, 2, 5, 4, 13]（保持原顺序）

2函数的定义与调用

函数将多行代码封装起来并命名，在需要时通过名字调用。好处：减少代码冗余，提高编程效率。函数必须 先定义，后调用。

基本语法
# 定义函数 def 函数名(): """文档注释（可选，说明函数作用）""" 函数中的代码 函数中的代码 # 调用函数 函数名()
📌 语法要点：
1. def 是关键字（define），函数名满足标识符规则（见名知意）
2. def 这行末尾需要 冒号，函数体需要 缩进
3. 函数定义 不执行 函数中的代码，只有调用才执行
4. PEP 8 规范：函数定义前后各留 两个空行
# 定义打招呼函数 def say_hello(): """打印三行问候""" print('hello 1') print('hello 2') print('hello 3') # 调用两次 → 代码只写一次 say_hello() say_hello()

定义函数的小技巧

1先写代码

不用函数，把多行代码直接写完，测试通过。

2加 def 起名

在多行代码上方写 def 函数名():。

3Tab 缩进

用 Tab 键将多行代码缩进到函数体中。

3参数 & 返回值

参数（形参 & 实参）

参数让函数更通用——函数中的数据值不是固定的，而是调用时传入的。

概念说明位置
形参（形式参数）函数定义时括号中的变量def add(a, b) 中的 a, b
实参（实际参数）调用时传入的具体数据值add(10, 20) 中的 10, 20
def add_2_num(a, b): # a, b 是形参 return a + b result = add_2_num(10, 20) # 10, 20 是实参 print(result) # 30 def add_3_num(a, b, c): return a + b + c print(add_3_num(1, 2, 3)) # 6
⚠️ 注意：有几个形参，调用时就必须传几个实参，数量不匹配会报 TypeError。

返回值 return

# return 的两个作用： # 1. 将数据值返回到调用的地方 # 2. 立即结束函数的执行（return 后的代码不会执行） def get_max(a, b): """返回两个数中的较大值""" if a > b: return a # 遇到 return，函数结束 else: return b print('我永远不会执行') # ❌ return 后不执行 num = get_max(10, 20) print(num) # 20 # 没有 return 的函数，返回值是 None def no_return(): print('我没有return') result = no_return() print(result) # None

函数嵌套调用

在一个函数中调用另一个函数。执行顺序：代码从上到下执行，调用时进入被调函数，执行完后回到调用处继续向下执行。

def input_username(): return input('请输入用户名:') def input_password(): return input('请输入密码:') def login(): """登录函数 — 嵌套调用""" if input_username() == 'admin' and input_password() == '123456': print('登录成功') else: print('用户名或密码错误') login()

4模块（Module）

Python 中每个代码文件都是一个 模块。模块中别人写好的变量、函数、类，可以导入后直接使用。自己写的模块文件名要满足标识符规则。

两种导入方式

方式一：import 模块名

import random # 使用：模块名.功能名 num = random.randint(1, 10) print(num) # 用 as 起别名 import random as r num = r.randint(1, 10)

多用于导入系统模块

方式二：from 模块名 import 功能名

from random import randint # 直接使用功能名，不用加模块名 num = randint(1, 10) print(num) # 导入自定义模块 from tools import add_2_num print(add_2_num(10, 20))

多用于导入自定义或第三方模块

__name__ 变量

导入模块时会执行模块中的代码。用 __name__ 可以避免测试代码被意外执行。

# 直接运行时：__name__ == '__main__' # 被导入时： __name__ == '模块名'（文件名） # tools.py 中的写法： def add_2_num(a, b): return a + b if __name__ == '__main__': # 这里的代码只有直接运行时才执行，导入时不执行 print(add_2_num(10, 20))
📌 导入顺序：① 先在当前目录查找 → ② 再查找 Python 系统目录 → ③ 找不到则报错。
注意：自定义文件名不要与系统模块同名（如不要命名为 random.py）。

5包（Package）

包是将多个模块放在一个目录中集中管理，并在目录中创建 __init__.py 文件（可以为空）。

包的结构

my_project/ ├── service/ # 包（有__init__.py） │ ├── __init__.py │ └── login_service.py ├── script/ # 包 │ ├── __init__.py │ └── test_login.py └── tools.py # 普通模块

三种导入方式

# 方式一 import service.login_service service.login_service.login() # 方式二 from service import login_service login_service.login() # 方式三（推荐，快捷键 Alt+回车） from service.login_service import login login() # 直接使用函数名

综合案例 — TPShop 登录功能模块化

# ===== login_service.py（开发功能）===== def login(username, password, verify_code): """模拟登录验证，返回验证结果字符串""" if verify_code != '8888': return '验证码错误' if username == 'admin' and password == '123456': return '登录成功' return '用户名或密码错误' # ===== test_login.py（测试代码）===== from service.login_service import login test_cases = [ ('admin', '123456', '8888', '登录成功'), ('admin', 'wrong', '8888', '用户名或密码错误'), ('admin', '123456', '0000', '验证码错误'), ] for u, p, c, expect in test_cases: result = login(u, p, c) status = '✅' if result == expect else '❌' print(f'{status} 期望:{expect} 实际:{result}')

Q1
为什么要使用函数？函数的好处是什么？
基础
+

① 减少代码冗余：重复的逻辑只需写一次，多次调用即可，不用复制粘贴。

② 提高编程效率：改动逻辑只需修改函数内部，不需要到处找代码修改。

③ 提高可读性：函数名本身就是注释，代码更易理解（见名知意）。

④ 便于测试：可以单独测试每个函数的功能，定位问题更快。

Q2
形参和实参的区别是什么？
基础
+

形参（形式参数）：函数 定义 时括号中的变量名，只是占位符，没有具体值。

实参（实际参数）：函数 调用 时传入的具体数据值，会赋给形参使用。

调用时实参值按位置依次赋给对应的形参，形参数量和实参数量必须一致（否则 TypeError）。

def add(a, b): # a, b → 形参 return a + b add(10, 20) # 10, 20 → 实参
Q3
return 关键字有几个作用？没有 return 的函数返回什么？
基础
+

return 有两个作用：
① 将数据值 返回 到调用的地方，供外部使用
② 立即结束 函数的执行，return 后面的代码不会执行

没有 return 或 return 后不跟值，函数返回 None（类似 append()、sort()）。

⚠️ 常见错误：函数有计算结果但忘记 return，在外部接收时得到 None。
Q4
函数的嵌套调用是什么？执行顺序是怎样的？
进阶
+

嵌套调用：在一个函数内部调用另一个函数。

执行顺序（四条规则）：
① 代码从上到下顺序执行
② 函数定义不执行函数体中的代码
③ 函数调用会进入被调函数执行
④ 被调函数执行完，回到调用处继续向下执行

实际应用：将复杂逻辑拆分成多个小函数，每个函数只做一件事，再通过嵌套组合。如登录：input_username() → input_password() → login()。
Q5
in 操作符对不同容器的判断规则是什么？
基础
+
容器in 判断的是示例
字符串是否包含该子串'he' in 'hello' → True
列表/元组是否包含该元素3 in [1,2,3] → True
字典是否包含该 键'name' in {'name':'x'} → True
集合是否包含该元素2 in {1,2,3} → True
⚠️ 字典中 in 判断的是键，不是值！判断值是否存在用 value in dict.values()。
Q6
集合 set 和列表 list 有什么区别？什么时候用集合？
进阶
+
list 列表set 集合
重复数据允许不允许（自动去重）
有序✅ 有序❌ 无序
下标访问✅ 支持❌ 不支持

集合常用于：列表去重、集合运算（交集/并集/差集）。

Q7
import 模块名 和 from 模块名 import 功能名 有什么区别？
基础
+

import 模块名：导入整个模块，使用时需要写 模块名.功能名()，命名空间清晰，不容易冲突。

from 模块名 import 功能名：只导入指定功能，使用时直接写 功能名()，更简洁；但如果两个模块有同名函数，会产生覆盖冲突。

💡 实践建议：导入系统模块（random/os/sys）用方式一；导入自定义模块或第三方库用方式二，更简洁且可用 Alt+Enter 快捷导入。
Q8
__name__ 变量的作用是什么？什么时候等于 '__main__'？
进阶
+

每个 Python 文件都有内置变量 __name__，其值由 Python 解释器自动维护：

① 直接运行该文件时：__name__ == '__main__'
② 被其他文件导入时：__name__ == '文件名（模块名）'

利用 if __name__ == '__main__': 可以将测试代码保护起来，只在直接运行时执行，被导入时自动跳过，避免影响导入方。

Q9
什么是模块？什么是包？两者有什么区别？
基础
+

模块（Module）：一个 .py 代码文件就是一个模块，文件名即模块名。

包（Package）：将多个模块放在同一个目录中，并在该目录创建 __init__.py 文件，这个目录就是一个包。

关系：包 > 模块。包是模块的容器，用于组织大型项目的代码结构。

Q10
函数的文档注释（docstring）怎么写？有什么用？
进阶
+

文档注释写在 def 的下方第一行，用 三对双引号 """...""" 包裹：

def add(a, b): """ 对两个数进行加法运算 :param a: 第一个数 :param b: 第二个数 :return: 两数之和 """ return a + b

查看方式：① Ctrl+Q 弹出提示 ② Ctrl+B 跳转到定义 ③ 按住Ctrl点击函数名

Q11
以下代码有什么问题？函数结果为什么是 None？
陷阱题
+
def add(a, b): result = a + b # ❌ 忘记写 return num = add(10, 20) print(num) # None ← 不是 30！

问题：函数计算了结果但没有 return，默认返回 None。外部接收到的是 None 而不是 30。

修复：在 result = a + b 后加上 return result，或直接 return a + b。

Q12
为什么自定义文件名不能和系统模块同名？模块的导入顺序是什么？
陷阱题
+

导入顺序：① 当前目录 → ② Python 系统目录 → ③ 报错

如果自定义文件命名为 random.py，当代码 import random 时，会先找到当前目录的 random.py，导入的是自己写的文件，导致系统的 random 模块无法使用。

⚠️ 常见坑：文件命名为 random.py, os.py, math.py 等系统模块名，会导致同名覆盖。建议用业务相关名字（如 tools.py, utils.py）。

13下面代码定义了一个求最大值的函数，哪行有问题？
