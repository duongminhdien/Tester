1按行读取 readline()

上节学习了 read() 一次读取全部内容。当文件很大时，更常用按行读取。

readline() 基本用法

文件对象.readline() # 一次读取一行的内容，返回读取到的字符串 # 如果读到文件末尾，返回空字符串 ''
with open('a.txt', encoding='utf-8') as f: buf = f.readline() # 读第一行 print(buf) # aaaaaa buf1 = f.readline() # 读第二行 print(buf1) # bbbbbb
💡 read() 和 readline() 共同点
两者都在读到文件末尾时返回空字符串 ''，可以用来判断文件是否读完。

读取大文件的正确姿势

大文件不要用 read()（会一次性加载到内存），用循环 readline()：

with open('a.txt', encoding='utf-8') as f: while True: buf = f.readline() if buf: # 非空字符串为 True print(buf, end='') else: # 空字符串 '' 为 False，文件读完 break

文本方式 vs 二进制方式

方式模式适用文件encoding 参数
文本r / w / a只能打开文本文件，会自动编码转换需要传 encoding='utf-8'
二进制rb / wb / ab可打开文本和二进制文件不能传 encoding 参数
⚠️ 重要规则
• 二进制文件（mp3、mp4、png、jpg）只能用二进制模式打开（rb/wb/ab）
• 二进制模式打开时，不能传 encoding 参数，否则报错
• 读取/写入的也是字节类型 bytes，不是字符串

2JSON 文件介绍

JSON（JavaScript Object Notation）是一种基于文本、独立于语言的轻量级数据交换格式。

🌐 独立于语言

不是某种语言特有的，Python、Java、C++、JavaScript 等都能使用

📦 轻量级

相同数据量，JSON 文件占用空间相对较小

📄 基于文本

本质是文本文件，可用记事本打开，但不能包含图片、视频

🔄 数据交换格式

前后端、不同系统之间交换数据的通用格式

📋 在测试中的应用
• 测试数据：把测试用例数据存为 JSON，方便参数化和数据驱动测试
• 接口测试：RESTful API 的请求体和响应体大多是 JSON 格式
• 配置文件：项目配置、环境变量等常用 JSON 保存
• 文件后缀名：.json

JSON 语法规则

  1. JSON 文件最外层是一个对象 {} 或一个数组 []，可以相互嵌套
  2. 对象由键值对组成，键必须是字符串（双引号包裹）
  3. 数据之间用逗号分隔，最后一个数据后不能加逗号
  4. 字符串必须用双引号 ""（不是单引号！）
  5. 文件后缀名是 .json

JSON 文件示例

{ "name": "小明", "age": 18, "isMan": true, "school": null, "like": ["听歌", "吃饭", "打豆豆"], "address": { "country": "China", "city": "广州" } }
❌ 常见 JSON 语法错误
• 字符串用单引号 'name' → 必须用双引号 "name"
• 最后一个键值对后多加了逗号 "age": 18,} → 不能加
• 键没用引号包裹 {name: "小明"} → 键必须是字符串
• 使用 Python 的 True/False/None → 应该是 true/false/null（小写）

4读取 JSON 文件

虽然可以用 read() 直接读 JSON 文件（本质就是文本文件），但读出来是字符串，取数据非常麻烦。Python 提供专门的 json 模块。

使用步骤

  1. 导包：import json
  2. 用 open 打开文件得到文件对象
  3. 用 json.load(文件对象) 直接转成 Python 的字典或列表
import json with open('info.json', encoding='utf-8') as f: buf = json.load(f) # 直接得到字典或列表 print(type(buf)) # <class 'dict'> print(buf.get('name')) # 小明 # 嵌套对象访问：链式调用 print(buf.get('address').get('city')) # 广州

读取数组形式的 JSON

如果 JSON 最外层是数组 []，json.load 返回的是列表，列表的每个元素是字典：

import json with open('info2.json', encoding='utf-8') as f: data_list = json.load(f) # 列表 for data in data_list: # 三目运算符：True 值 if 条件 else False 值 sex = "男" if data.get('isMan') else "女" print(f"姓名: {data.get('name')}, " f"年龄: {data.get('age')}, " f"性别: {sex}, " f"城市: {data.get('address').get('city')}")
💡 三目运算符（条件表达式）
值1 if 条件 else 值2 — 条件为 True 取值1，否则取值2。
比 if/else 更简洁，适合简单的二选一场景。

5写入 JSON 文件

把 Python 中的字典或列表写成 JSON 文件，使用 json.dump()。

import json info = {'name': '小明', 'age': 18} with open('info.json', 'w', encoding='utf-8') as f: # 基础写法：中文会被转成 \uXXXX 形式 # json.dump(info, f) # 推荐写法：直接显示中文 + 缩进美化 json.dump(info, f, ensure_ascii=False, indent=2)
📝 两个关键参数
• ensure_ascii=False — 直接显示中文字符（默认 True 会转成 \u5c0f 这种 unicode 编码）
• indent=2 — 用 2 个空格缩进，文件更美观便于阅读

json 模块 4 个核心方法对比

方法方向说明
json.load(f)JSON 文件 → Python读取并解析 JSON 文件
json.dump(obj, f)Python → JSON 文件写入 Python 数据到文件
json.loads(s)JSON 字符串 → Python解析 JSON 字符串（s = string）
json.dumps(obj)Python → JSON 字符串把 Python 数据转成字符串
🎯 记忆技巧：带 s 操作字符串
• load / dump 操作文件对象
• loads / dumps（多个 s）操作字符串（接口测试中经常用，因为响应是字符串）

6异常基本介绍

异常是程序运行时遇到错误的统称。Python 解释器遇到错误会停止程序执行并提示错误信息，这个动作叫做"抛出异常"（raise）。

异常信息的格式

FileNotFoundError: [Errno 2] No such file or directory: 'aaaa.txt' ZeroDivisionError: division by zero ValueError: invalid literal for int() with base 10: '78.1'

异常信息由两部分组成：异常类型（如 ValueError）+ 错误描述（具体原因）。

常见异常类型

异常类型触发场景
FileNotFoundError打开不存在的文件
ZeroDivisionError除数为 0
ValueError类型转换失败（如 int('abc')）
TypeError类型不匹配（如 字符串 + 数字）
NameError使用了未定义的变量
KeyError字典中不存在的 key
IndexError列表索引超出范围
AttributeError对象没有这个属性/方法

7异常捕获 try...except

默认遇到异常程序会终止。如果希望程序遇到异常不终止而是继续执行，需要使用异常捕获。

基本语法

try: 可能发生异常的代码 except: # 可以捕获任意类型的异常 发生异常执行的代码

示例：输入数字

num = input('请输入数字:') try: num = int(num) print(num) except: print('请输入正确的数字')

捕获指定类型的异常

不同异常类型可以有不同的处理逻辑：

try: num = int(input('请输入一个整数数字:')) num1 = 8 / num print(num1) except ValueError: # 类型转换错误 print('输入的内容非数字') except ZeroDivisionError: # 除零错误 print('不能输入数字 0')

捕获未知类型的异常（最常用）

实际开发中，未必能预料所有异常类型，使用 Exception 作为兜底：

try: num = int(input('请输入数字:')) num1 = 8 / num print(num1) except Exception as e: # Exception 是大部分异常的父类 print(f'发生了异常: {e}') # e 是异常对象，print 会显示异常信息
💡 as 关键字
except Exception as e 把异常对象赋给变量 e，可以通过 print(e) 或 str(e) 获取异常的描述信息。

8异常捕获完整结构

完整的异常捕获结构包含 5 个部分：

try:
可能发生异常的代码
except 异常类型:
发生了指定类型的异常时执行的代码（可写多个）
except Exception as e:
发生了其他类型异常时执行的代码（兜底）
else:
没有发生异常时执行的代码
finally:
不管有没有发生异常，都会执行的代码（清理资源用）

完整示例：判断奇偶数

# 1. 获取用户输入 num = input('请输入数字:') try: # 2. 类型转换（可能发生异常） num = int(num) except Exception as e: # 3. 转换失败，提示输入错误 print('输入错误', e) else: # 4. 转换成功（没异常），判断奇偶 if num % 2 == 0: print('偶数') else: print('奇数') finally: # 5. 不管什么情况都会执行 print('程序运行结束')

对比方案：用字符串方法判断

num = input('请输入数字:') if num.isdigit(): # 判断字符串是否为纯数字 num = int(num) if num % 2 == 0: print('偶数') else: print('奇数') else: print('输入错误') print('程序运行结束')
💡 字符串.isdigit()
判断字符串是否为纯数字，是返回 True，否则 False。
注意：'12.5'.isdigit() 返回 False（因为小数点不是数字字符）。

9异常传递与抛出异常

异常传递

这是 Python 自动实现的机制，不需要写代码。

在函数嵌套调用过程中，如果发生了异常但没有被捕获，异常会传递到上层调用的地方，直到被捕获为止；如果一直没被捕获，程序就会终止并报错。

def a(): print(1 / 0) # 这里异常，没捕获，传递给 b def b(): a() # 异常继续传递给 c def c(): try: b() except Exception as e: print(f'最终在 c 中捕获: {e}') c() # 最终在 c 中捕获: division by zero

抛出异常 raise

程序执行中之所以会发生异常，是因为代码遇到了 raise 关键字。

raise 的作用：主动抛出一个异常，让程序终止执行。

📌 应用场景
自己写代码模块给别人使用时，可以在不满足条件的情况下，用 raise 抛出异常，强制使用者按照规定使用：
def set_age(age): if age < 0 or age > 120: raise ValueError(f'年龄非法: {age}') print(f'设置年龄为 {age}') set_age(200) # ValueError: 年龄非法: 200

📄 read() 一次性读

6异常捕获完整结构图

5 个关键字 + 它们的执行时机：

try:
放可能发生异常的代码（必选）
except 异常类型A:
指定类型 A 的异常发生时执行
except Exception as e:
兜底捕获其他类型异常，e 是异常对象
else:
没有任何异常发生时才执行
finally:
无论是否发生异常，都会执行（常用于释放资源、关闭文件）
🎯 执行顺序总结
• 无异常：try → else → finally
• 有异常被捕获：try → except → finally
• 有异常未捕获：try → finally → 抛出异常
• finally 一定会执行，这是它的核心特性

7异常传递演示

函数嵌套时，未捕获的异常会沿调用链向上传递，直到被捕获或最终报错。

🔗 异常沿调用链传递
def a(): print(1 / 0) ┐ ① 发生 ZeroDivisionError def b(): a() ┤ ② 传递到 b（b 没处理） def c(): try: b() ┤ ③ 传递到 c except Exception as e: print(e) ┘ ④ c 中捕获，停止传递 c()

Q1
read()、readline() 和遍历文件对象的区别？
基础
+

三种读法对比：

  • read()：一次读取全部内容，返回字符串。适合小文件，大文件会占用大量内存。
  • readline()：一次读取一行，返回字符串。文件末尾返回 ''。适合按行处理。
  • for line in f:：直接遍历文件对象，最简洁，按行处理大文件的推荐方式。

判断文件读完： read 和 readline 都通过返回的空字符串 '' 来判断是否到末尾。

Q2
什么是 JSON？它有什么特点？
基础
+

JSON（JavaScript Object Notation）是一种基于文本、独立于语言的轻量级数据交换格式。

特点：

  • 基于文本：本质是文本文件，可用记事本打开
  • 独立于语言：所有编程语言都能读写，不是某语言专有
  • 轻量级：相比 XML 等格式，文件更小
  • 易读易写：人类和机器都容易理解

在测试中的应用：存储测试数据、配置文件、API 请求/响应体。文件后缀名 .json。

Q3
如何读取 JSON 文件？写出完整代码。
基础
+

3 步：

  1. import json 导入模块
  2. 用 open 打开 .json 文件
  3. 用 json.load(文件对象) 解析，得到 Python 的字典或列表
import json with open('info.json', encoding='utf-8') as f: data = json.load(f) print(data.get('name'))

注意：JSON 最外层是 {} → 得到字典；最外层是 [] → 得到列表。

Q4

Q5
写入 JSON 时，中文显示成 \uXXXX 怎么办？
进阶
+

原因：json.dump 默认 ensure_ascii=True，把非 ASCII 字符（包括中文）转成 unicode 转义序列。

解决：显式设置 ensure_ascii=False

import json data = {'name': '小明'} # ❌ 默认：会写成 {"name": "\u5c0f\u660e"} json.dump(data, f) # ✅ 正确：直接显示中文 + 缩进美化 json.dump(data, f, ensure_ascii=False, indent=2)

同时打开文件时也要加 encoding='utf-8'，否则可能仍有乱码。

Q6
JSON 和 Python 字典看着一样，有什么区别？
陷阱
+

它们不一样！JSON 是数据交换格式（字符串），Python 字典是数据结构（对象）。具体差异：

对比项JSONPython 字典
字符串引号只能双引号 "name"单/双引号都可以
布尔值true / false（小写）True / False
空值nullNone
末尾逗号不允许允许

所以不能直接用 eval() 解析 JSON，要用 json.loads()。

Q7
什么是异常？为什么要捕获异常？
基础
+

异常是程序运行时遇到错误的统称。Python 解释器遇到错误会停止程序执行并提示错误信息（异常类型 + 错误描述）。

为什么捕获异常：

  • 提升程序健壮性：用户输入不可控，文件可能不存在，网络可能中断…让程序优雅应对
  • 友好的错误提示：不直接给用户看一堆错误堆栈，而是给出可理解的提示
  • 资源清理：发生异常时仍能关闭文件、释放连接（用 finally）
  • 程序不终止：异常处理后可以继续执行后续代码
Q8
异常捕获的完整结构是怎样的？写出来。
基础
+
try: 可能发生异常的代码 except 异常类型: 发生指定类型异常时执行 except Exception as e: 发生其他类型异常时执行（兜底） else: 没有发生异常时执行 finally: 不管有没有发生异常都会执行

关键点：

  • try 必选，其他都是可选
  • except 可以写多个，按顺序匹配
  • Exception 是大部分异常的父类，放最后做兜底
  • finally 一定会执行，常用于关闭文件、释放资源
Q9
except、else、finally 的执行时机分别是什么？
进阶
+
  • except：try 中发生异常，且异常类型匹配时执行
  • else：try 中没有发生任何异常时执行（注意不是 except 的备选）
  • finally：无论是否发生异常，最终一定执行

三种执行路径：

  1. 无异常：try → else → finally
  2. 异常被捕获：try（中途） → except → finally
  3. 异常未捕获：try（中途） → finally → 抛出异常

常见应用：finally 用于资源清理（关文件、关数据库连接），保证一定执行。

Q10
下面代码会输出什么？
陷阱
+
try: print('A') print(1 / 0) print('B') except ValueError: # 注意类型 print('C') except Exception: print('D') else: print('E') finally: print('F')

答案：A D F

解析：

  • 打印 A → 然后 1/0 抛出 ZeroDivisionError
  • B 不会执行（异常中断）
  • 第一个 except 是 ValueError，不匹配
  • 第二个 except Exception 是兜底，匹配 → 打印 D
  • else 仅在无异常时执行，不会执行 E
  • finally 必执行 → 打印 F
Q11
什么是异常传递？什么是抛出异常（raise）？
进阶
+

异常传递：Python 自动实现的机制，在函数嵌套调用中，未被捕获的异常会沿调用链向上传递，直到被捕获或最终终止程序。

raise 抛出异常：主动让代码报错。两个用途：

  1. 验证输入：参数不合法时抛出异常，强制使用者按规定使用
    def set_age(age): if age < 0 or age > 120: raise ValueError('年龄不合法')
  2. 重新抛出：捕获后处理一下，再抛给上层
    try: do_something() except Exception as e: log_error(e) # 记录日志 raise # 重新抛出
Q12
JSON 和异常处理在自动化测试中如何应用？
场景
+

JSON 的应用：

  • 测试数据驱动：把测试用例的输入/期望结果存为 JSON，配合 pytest 参数化（@pytest.mark.parametrize）
  • 接口测试：requests 库的响应 response.json() 直接得到字典；构造请求体用 json=payload 参数
  • 配置管理：把数据库连接、URL、账号信息存在 config.json
  • 测试报告：allure 等报告工具底层用 JSON 存储测试结果

异常处理的应用：

  • 断言失败处理：try 包裹断言，捕获后记录详细日志
  • 元素查找超时：Selenium 的 NoSuchElementException 捕获后重试或截图
  • 测试稳定性：网络异常、文件不存在等情况优雅处理，避免一个用例失败影响整个测试套件
  • 清理资源：用 finally 保证测试结束后关闭浏览器、断开数据库连接
