1变量进阶

引用（了解）

变量和数据在内存中分别开辟空间，变量中存储的是数据所在内存的地址，这个地址就叫做引用。

  • 赋值运算符 = 会改变变量的引用
  • Python中所有数据的传递，传递的都是引用（地址）
  • 使用 id(变量) 可以查看变量的引用（内存地址）
a = 1 # 变量 a 指向数据 1 的地址 b = a # 变量 b 保存 a 的引用（同一地址） print(f'a: {a}, id: {id(a)}') # a: 1, id: 4391875872 print(f'b: {b}, id: {id(b)}') # b: 1, id: 4391875872（同一地址） a = 2 # 改变 a 的引用（指向新地址），不影响 b print(f'a: {a}') # a: 2 print(f'b: {b}') # b: 1（b 未受影响）

可变类型与不可变类型（记住）

判断标准：不使用等号（=），能不能修改数据的值？

❌ 不可变类型（修改后id变化）

  • int / float / bool（数字类型）
  • str（字符串）
  • tuple（元组）
x = 10 x = 20 # 不是修改，是改变引用 s = 'hello' s[0] = 'H' # ❌ 报错，字符串不可修改

✅ 可变类型（修改后id不变）

  • list（列表）
  • dict（字典）
  • set（集合）
lst = [1, 2, 3] lst.append(4) # ✅ 修改数据，id不变 d = {'a': 1} d.pop('a') # ✅ 修改数据，id不变
⚠️ 元组包含列表的特殊情况：
my_tuple = (1, 2, [10, 20])
元组本身不可变（存储的是列表的地址），但元组中的列表是可变的，可以修改列表内的元素，元组的id不变。

局部变量与全局变量（理解掌握）

类型定义位置访问范围生命周期
局部变量函数内部定义只能在当前函数内使用函数调用时创建，函数结束时销毁
全局变量函数外部定义任意函数内都可以访问（读取）程序启动时创建，程序结束时销毁
g_num = 10 # 全局变量 def func_1(): print(g_num) # ✅ 可以读取全局变量 → 10 def func_2(): g_num = 20 # ⚠️ 定义的是局部变量，不影响全局 print(g_num) # 20（局部变量） def func_3(): global g_num # ✅ 声明使用全局变量 g_num = 30 # 修改全局变量 print(g_num) # 30
📌 关键规则：
1. 函数内部可以读取全局变量（无需声明）
2. 函数内部想要修改全局变量的引用，必须用 global 关键字声明
3. 如果函数内有与全局变量同名的局部变量，函数内使用的是局部变量
4. 对可变类型（list/dict）调用方法修改其内容，不需要 global（没有改变引用）

2函数进阶

函数返回多个数据值

函数返回多个数据时，一般将它们组成元组进行返回。

def calc(a, b): """返回两个数的和及差""" return a + b, a - b # 返回元组 (和, 差) result = calc(10, 20) print(result) # (30, -10) s, d = calc(10, 20) # 元组拆包 print(s, d) # 30 -10

参数传递方式

📍 位置传参

按形参定义的顺序传递实参

show_info('小明', 18)

🔑 关键字传参

指定参数名传值，顺序可变

show_info(age=18, name='张三')
⚠️ 注意：混合使用时，位置参数必须写在关键字参数前面；同一个形参只能接收一个实参值。

缺省参数（默认参数）

定义函数时给形参设置默认值，调用时可以不传该参数，使用默认值；传了则用传入的值。

⚠️ 规则：缺省参数必须写在普通参数的后边！
def show_info(name, age=18, sex='保密'): print(name, age, sex) show_info('张三', 18, '男') # 张三 18 男 show_info('李四') # 李四 18 保密（使用默认值） show_info('王五', 19) # 王五 19 保密 show_info('赵六', sex='男') # 赵六 18 男（跳过age用默认）

不定长参数（多值参数 / *args）

函数定义时不确定参数数量，在形参前加 *，可接收任意多个位置传参的数据，类型为元组。一般写作 *args。

def func(*args): print(args) func() # () 空元组 func(1, 2, 3) # (1, 2, 3) # 实际应用：任意多个数字求和 def my_sum(*args): # args 是元组 num = 0 for i in args: num += i return num print(my_sum(1, 2, 3)) # 6 # 列表/元组拆包传参：在列表前加 * 进行拆包 my_tuple = (1, 2, 3, 4, 5) print(my_sum(*my_tuple)) # 15（拆包后等同于 my_sum(1,2,3,4,5)）

匿名函数（lambda）

使用 lambda 关键字定义的简洁函数表达式，只能写一行代码，实现简单功能。

# 语法：lambda 参数, 参数: 一行代码（返回值） # 两数乘积 lambda a, b: a * b # 取字典中 age 键的值 lambda x: x['age'] # 匿名函数的核心应用：作为函数的参数（key参数） user_list = [ {'name': '张三', 'age': 22}, {'name': '李四', 'age': 24}, {'name': '王五', 'age': 21} ] # 按 age 升序排列 user_list.sort(key=lambda x: x['age']) print(user_list) # [{'name': '王五', 'age': 21}, {'name': '张三', 'age': 22}, {'name': '李四', 'age': 24}]
📌 参数顺序规律：
def 函数名(普通参数, *args, 缺省参数):
• 普通参数在最前
• 不定长参数 *args 在中间
• 缺省参数在最后

1. 以下代码输出什么？解释原因。

查看答案 ›

10. 如果全局变量是可变类型（如列表），在函数内什么情况下需要 global 声明？
综合题：考察可变类型+全局变量的深入理解
查看答案 ›
list1 = [1, 2] # ✅ 不需要 global：只是修改列表内容（不改变引用） def func_a(): list1.append(10) # 修改内容，list1还是那个list1 list1.pop() # 修改内容，不需要global # ❌ 需要 global：要让list1指向一个全新的列表（改变引用） def func_b(): global list1 # 声明：我要修改全局变量list1的引用 list1 = [1] # 让 list1 指向一个新列表 # ❌ 不加global时，list1 = [1,1] 定义的是局部变量，不影响全局 def func_c(): list1 = [1, 1] # 局部变量，不影响外部的全局list1 list1.append(0)

🏫综合案例 — 学生管理系统

需求说明：学生信息包含 name（姓名）、age（年龄）、sex（性别）。实现菜单驱动的管理系统，支持：添加/删除/修改/查询单个/查询所有/退出。

数据结构设计

# 存储所有学生信息的列表（全局变量） stu_list = [] # 单个学生信息用字典存储 # 示例：{'name': '小明', 'age': 18, 'gender': '男'}

完整实现代码

# ====== 学生管理系统 完整版 ====== stu_list = [] # 全局学生列表 def show_menu(): """打印功能菜单""" print('1. 添加学生') print('2. 删除学生') print('3. 修改学生信息') print('4. 查询单个学生信息') print('5. 查询所有的学生信息') print('6. 退出系统') def insert_student(): """添加学生（姓名不能重复）""" name = input('请输入学生名字:') for stu in stu_list: if stu['name'] == name: print('---------该学生已存在----------') return # 重名，直接退出 age = input('请输入学生年龄:') gender = input('请输入学生性别:') stu_dict = {'name': name, 'age': int(age), 'gender': gender} stu_list.append(stu_dict) print('==============学生信息添加成功====================') def remove_student(): """删除学生""" name = input('请输入要删除的学生的名字:') for stu in stu_list: if stu['name'] == name: stu_list.remove(stu) break else: print('***该学生不存在，请重新操作***') def modify_student(): """修改学生信息""" name = input('请输入要修改的学生的名字:') for stu in stu_list: if stu['name'] == name: stu['age'] = int(input('请输入新的年龄:')) break else: print('***该学生不存在，请重新操作***') def search_student(): """查询单个学生""" name = input('请输入要查询的学生姓名:') for stu in stu_list: if stu['name'] == name: print(f'姓名:{stu["name"]}, 年龄:{stu["age"]}, 性别:{stu["gender"]}') break else: print(f'名字叫[{name}]的学生不存在') def show_all_info(): """查询所有学生""" if len(stu_list) > 0: for stu in stu_list: print(f'姓名:{stu["name"]}, 年龄:{stu["age"]}, 性别:{stu["gender"]}') else: print('暂时没有学生信息') def main(): """主程序（while循环驱动菜单）""" while True: show_menu() opt = input('请输入用来选择的操作编号:') if opt == '1': insert_student() elif opt == '2': remove_student() elif opt == '3': modify_student() elif opt == '4': search_student() elif opt == '5': show_all_info() elif opt == '6': print('感谢使用学生管理系统，拜拜！') break else: print('输入有误，请重新输入') continue input('...... 回车键继续操作.......') if __name__ == '__main__': main()

知识点解析

🔑 重名检查逻辑

在 insert_student 中，遍历所有学生检查姓名是否重复，找到重名则直接 return 退出，避免重复添加。

🔄 for-else 查找逻辑

在删除/修改/查询中使用 for-else：找到后 break 退出（跳过else），未找到时 else 执行提示。

🔄 while True 主循环

主程序用 while True 持续运行。选择6时 break 退出循环；输入错误时 continue 直接回到循环头。

🏷️ if __name__ == '__main__'

Python 的标准入口写法。当文件被直接运行时 __name__ 为 '__main__'，被其他文件导入时不会自动执行 main()。

12id(变量) 函数的作用是？
✅ 正确答案：B – id(x) 返回对象的内存地址（引用）。可变类型修改内容后 id 不变；不可变类型"修改"后 id 改变（实际创建了新对象）。
13学生管理系统中，主程序使用 while True 循环，退出系统时应该用什么语句？
✅ 正确答案：C – 选择"6. 退出系统"时，用 break 跳出 while True 循环，程序自然结束。continue 是跳到循环开头；return 用于退出函数。
14元组中包含可变类型（如列表），能修改其中列表的内容吗？
✅ 正确答案：B – 元组不可变指的是元组存储的引用（地址）不能修改。但如果元组中存的是列表的地址，列表的内容是可以修改的，因为修改列表内容不改变列表的地址。例：t=(1,[10,20]); t[1].append(30) ✅。
15拆包传参：已有元组 t = (1, 2, 3)，如何将其拆包传给 my_sum(*args)？
✅ 正确答案：B – 在列表或元组前加 * 进行拆包：my_sum(*t) 等同于 my_sum(1, 2, 3)。直接 my_sum(t) 会将整个元组作为一个参数传入 args[0]。
