1面向对象概述

面向对象编程（OOP，Object Oriented Programming）是一种编程思想，它指导我们如何组织代码。Python 是一门完全的面向对象语言。

面向过程 vs 面向对象

对比项面向过程面向对象
关注点实现的细节（怎么做）问题的结果（谁来做）
核心函数类和对象
适用场景小型项目中大型项目
代码组织按步骤、流程按角色、职责
复用性较弱较强
💡 通俗理解
• 面向过程：把大象装冰箱要 3 步——打开冰箱、装大象、关上冰箱。我亲自一步步做。
• 面向对象：找一个"搬运工"对象，让他来装大象。我只关心找谁做，不关心具体怎么做。

2类与对象

什么是类（Class）

  • 类是对具有相同特征或行为的事物的统称
  • 类是抽象的，不能直接使用
  • 类指代多个事物（一类事物）
  • 在 Python 中使用关键字 class 定义

什么是对象（Object）

  • 对象是由类创建出来的具体存在的事物
  • 对象是具体的，可以直接使用
  • 对象指代一个具体事物
  • 在代码中通过类来创建（实例化）对象
🎯 类 vs 对象 举例
• 苹果 → 类，红苹果 → 类，小明手里那个红苹果 → 对象
• 狗 → 类，大黄狗 → 类，李四家那条大黄狗 → 对象
• 类是"模板"，对象是用模板"造出来的"具体实例

类的三要素

1类名

给一类事物起的名字。遵循大驼峰命名法（所有单词首字母大写），如 Person、LoginPage、HouseItem

2属性

事物的特征（是什么）。例如人的姓名、年龄、身高，狗的颜色、名字

3方法

事物的行为（能做什么）。例如人能跑能吃，狗能叫能摇尾巴

3定义类的语法

基本语法

class 类名: # 在 class 的缩进中定义类的属性和方法 def 方法名(self): # 方法的本质就是函数 pass
⚠️ 注意事项
• 类名遵循大驼峰命名法：MyClass，不是 my_class
• 类中定义的函数叫做方法（method），第一个参数必须是 self
• 类的代码块要正确缩进（4 个空格）

完整示例：定义猫类

class Cat: def eat(self): """吃鱼的方法""" print('小猫爱吃鱼...') def drink(self): """喝水的方法""" print('小猫要喝水')

创建对象（实例化）

# 语法：变量 = 类名() tom = Cat() # 通过对象调用类中的方法 tom.eat() # 输出：小猫爱吃鱼... tom.drink() # 输出：小猫要喝水
💡 本质理解
tom = Cat() 中：
• Cat() 创建一个对象
• 变量 tom 中保存的是对象的引用地址（内存地址）
• 同一个类可以创建出无数个对象，每个对象的内存地址不同

4self 参数详解

从函数语法上看，self 是个普通的形参，名字可以是任意变量名，但习惯上叫 self。

self 的特殊之处

  • 调用方法时不需要手动传递 self 参数
  • Python 解释器会自动把调用这个方法的对象作为参数传给 self
  • 因此 self 就是调用该方法的对象本身
class Cat: def eat(self): # self 是调用这个方法的对象 print(f'self: {id(self)}') print('小猫爱吃鱼...') tom = Cat() print(f"tom: {id(tom)}") tom.eat() # tom 调用，self 就是 tom（地址相同） blue = Cat() print(f"blue: {id(blue)}") blue.eat() # blue 调用，self 就是 blue
🎯 一句话记住 self
self 就是当前调用方法的那个对象自己。谁调方法，self 就是谁。

5属性的操作

属性表示事物的特征。我们可以给对象添加属性，也可以获取对象的属性值。

在类外操作属性

# 添加 / 修改属性 对象.属性名 = 属性值 # 获取属性值 print(对象.属性名)

在方法内操作属性（通过 self）

class Cat: def eat(self): # self 是对象，通过 self 访问/修改属性 print(f'小猫{self.name}爱吃鱼...') tom = Cat() tom.name = '汤姆' # 给对象添加 name 属性 tom.eat() # 输出：小猫汤姆爱吃鱼...
❌ 这种方式不好
在类外手动添加属性 tom.name = '汤姆' 不规范：
• 容易忘记添加，导致方法访问属性时报错 AttributeError
• 每个对象都要单独写一遍，代码冗余
• 更好的方式是用 __init__ 方法初始化属性 ↓

6魔法方法 __init__

Python 中有一类方法，以两个下划线开头和结尾（如 __init__、__str__），在满足某个条件时自动调用，称为魔法方法（Magic Method）。

1调用时机

什么情况下会被自动调用

2应用场景

这个方法用来做什么

3注意事项

使用时容易踩的坑

__init__ 方法

要点说明
调用时机在创建对象之后自动调用
应用场景初始化对象，给对象添加属性
注意事项方法名不要写错；可变属性可通过参数传入
class Cat: def __init__(self, name): # 创建对象后自动调用，给对象添加 name 属性 self.name = name def eat(self): print(f"小猫 {self.name} 爱吃鱼") # 创建对象时必须传入 name 参数 blue = Cat('蓝猫') blue.eat() # 小猫 蓝猫 爱吃鱼 black = Cat('黑猫') black.eat() # 小猫 黑猫 爱吃鱼
⚠️ 哪些情况会自动调用 __init__？
• Cat() — 会（创建对象）
• tom = Cat() — 会（创建对象）
• Cat — 不会（只是引用类）
• tom = Cat — 不会（只是把类赋给变量，tom 也变成类）
• b = blue — 不会（只是引用传递）

7魔法方法 __str__

要点说明
调用时机使用 print(对象) 打印对象时自动调用
应用场景定制 print(对象) 时输出的内容（通常输出属性信息）
注意事项必须 return 一个字符串

对比：有无 __str__

❌ 没有定义 __str__

print(tom) # 输出对象的内存地址： # <__main__.Cat object at 0x...>

✅ 定义了 __str__

print(tom) # 输出 __str__ 的返回值： # 姓名: 汤姆, 年龄: 3

完整示例

class Cat: def __init__(self, name, age): self.name = name self.age = age def __str__(self): # 注意：用 return 而不是 print return f"姓名: {self.name}, 年龄: {self.age}" tom = Cat('汤姆', 3) print(tom) # 姓名: 汤姆, 年龄: 3
❌ 常见错误
在 __str__ 中用 print 而非 return：
def __str__(self): print(f"姓名: {self.name}") ← 错误
这样会返回 None，导致 TypeError: __str__ returned non-string

8封装思想

📦 什么是封装
封装就是根据需求，把相关的属性和方法定义到同一个类中。这是面向对象的核心思想之一。

封装的步骤（完整流程）

  1. 设计类：分析需求，找出类的三要素（类名、属性、方法）
  2. 定义类：用 class 关键字写出类的代码
  3. 创建对象：使用 类名() 实例化
  4. 调用方法：通过对象访问类中的属性和方法

类名提取技巧：名词提炼法

📝 方法
分析整个业务流程，找出所有名词，通常这些名词就是类名。
例如："进入登录页面，输入用户名、密码、验证码后点击登录按钮"
→ 名词：登录页面、用户名、密码、验证码、登录按钮
→ 类名：LoginPage（用户名等通常作为属性）

完整案例：小明爱跑步

需求：小明体重 75.0 公斤，跑步会减肥 0.5 公斤，吃东西体重增加 1 公斤。

class Person: def __init__(self, name, weight): self.name = name self.weight = weight def __str__(self): return f"{self.name} 目前体重 {self.weight} kg" def run(self): """跑步：体重减少 0.5kg""" self.weight -= 0.5 print(f'{self.name} 跑步了，体重 -0.5 kg') def eat(self): """吃东西：体重增加 1kg""" self.weight += 1 print(f'{self.name} 大餐一顿，体重 +1 kg') if __name__ == '__main__': xming = Person('小明', 75.0) print(xming) xming.run() xming.eat() print(xming)

每次执行 print(对象) 时，Python 会自动调用 __str__ 方法，并打印它返回的字符串。

9. 定义 Dog 狗类，属性 name、color。方法 bark（叫）和 shake（摇尾巴）。在 bark 方法中接收参数 visitor，如果是 "家人" 就调用 shake，否则汪汪叫。

10. 【作业题 4 · 摆放家具】定义 House（房子，属性：户型/总面积/剩余面积/家具列表）和 HouseItem（家具，属性：名字/占地面积）两个类。add_item 方法判断剩余面积是否足够，足够则添加并扣减面积，不够则提示换大房子。创建席梦思(4)、衣柜(2)、餐桌(1.5) 放入"三室一厅"(100㎡)。
查看答案 ›
class HouseItem: """家具类""" def __init__(self, name, area): self.name = name self.area = area def __str__(self): return f'{self.name} 占地面积 {self.area} 平米' class House: """房子类""" def __init__(self, h_type, area): self.h_type = h_type self.total_area = area self.free_area = area # 剩余面积=总面积 self.item_list = [] # 刚开始没有家具 def __str__(self): return (f'户型:{self.h_type}、总面积:{self.total_area}平米、' f'剩余面积:{self.free_area}平米、家具列表:{self.item_list}') def add_item(self, item): """添加家具，item 是家具对象""" if self.free_area > item.area: print(f'添加家具: {item.name}') self.item_list.append(item.name) self.free_area -= item.area else: print(f'房子剩余面积不足，换个大房子吧.....') if __name__ == '__main__': bed = HouseItem('席梦思', 4) chest = HouseItem('衣柜', 2) table = HouseItem('餐桌', 1.5) house = House('三室一厅', 100) print(house) house.add_item(bed) house.add_item(chest) house.add_item(table) print(house) # 户型:三室一厅、总面积:100、剩余面积:92.5、家具列表:['席梦思','衣柜','餐桌']

+

面向对象（OOP）是一种编程思想，把现实世界的事物抽象成类，并通过对象来组织代码。Python 中的核心是"类"和"对象"。

主要区别：

  • 面向过程：关注"怎么做"，按步骤组织代码，核心是函数。适合小型项目（如脚本工具）。
  • 面向对象：关注"谁来做"，按角色/职责组织代码，核心是类与对象。适合中大型项目（如自动化测试框架）。

测试场景举例：编写 UI 自动化时，面向对象就是把每个页面抽象为一个类（LoginPage、HomePage），把页面操作封装为方法 — 这就是 Page Object Model（POM）模式的基础。

Q2
类的三要素是什么？请举例说明。
基础
+

类的三要素是：类名、属性、方法。

  • 类名：一类事物的统称，遵循大驼峰命名法（首字母大写）。
  • 属性：事物的特征，即"是什么"。
  • 方法：事物的行为，即"能做什么"。

例子：设计一个登录页面类

  • 类名：LoginPage
  • 属性：username、password、verify_code
  • 方法：login()

类名的提取技巧：名词提炼法，从业务描述中找名词，通常就是类名。

Q4
谈谈你对 self 的理解。
基础
+

self 的本质：self 是类的方法中的第一个参数，它代表调用该方法的对象本身。

关键要点：

  • 从语法上看，self 只是一个普通的形参，名字可以改成任意合法变量名，但约定俗成用 self。
  • 调用方法时不需要手动传递 self，Python 解释器会自动把调用对象作为第一个参数传入。
  • 因此 tom.eat() 等价于 Cat.eat(tom)，self 就是 tom。
  • 在方法内通过 self.属性名 访问/修改属性，通过 self.方法名() 调用其他方法。

一句话：谁调方法，self 就是谁。

Q5
__init__ 方法的作用是什么？什么时候被调用？
基础
+

__init__ 是一个魔法方法（特殊方法），也叫初始化方法或构造方法。

调用时机：在创建对象之后自动调用，每次 类名() 都会触发一次。

主要作用：初始化对象，给对象添加属性。把变化的属性作为参数传入，避免在类外手动添加。

使用示例：

class Cat: def __init__(self, name, age): self.name = name self.age = age tom = Cat('汤姆', 3) # 自动调用 __init__

注意：方法名必须是左右各两个下划线（不是 _init_）。

Q6
__str__ 方法的作用是什么？必须返回什么？
基础
+

__str__ 是一个魔法方法。

调用时机：当使用 print(对象) 打印对象时自动调用。

主要作用：定制打印对象时的输出内容，通常用来展示对象的属性信息。

注意事项：

  • 必须 return 一个字符串，不能用 print。
  • 如果不定义 __str__，print(对象) 默认输出对象的内存地址，对用户不友好。
  • 返回非字符串会报错：TypeError: __str__ returned non-string。
Q7
什么是魔法方法？常见的有哪些？
进阶
+

魔法方法（Magic Methods）是 Python 中一类以双下划线开头和结尾的特殊方法，在满足特定条件时被自动调用，无需手动调用。

学习魔法方法 3 要点：

  1. 调用时机（什么情况下自动调用）
  2. 应用场景（用来做什么）
  3. 注意事项（容易踩的坑）

常见魔法方法：

方法调用时机作用
__init__创建对象后初始化属性
__str__print(对象)定制打印输出
__del__对象被销毁前清理资源
__len__len(对象)返回长度
__eq__对象 == 对象定制相等比较
Q8
封装是什么？为什么要封装？
进阶
+

封装（Encapsulation）是面向对象的三大特性之一（封装/继承/多态）。

定义：根据需求，把相关的属性和方法定义到同一个类中。把数据和处理数据的逻辑"打包"起来。

封装的好处：

  • 代码组织清晰：相关功能集中在一处，便于维护。
  • 提高复用性：定义一次类，可创建多个对象。
  • 隐藏实现细节：使用者只需调用方法，不必关心内部实现。
  • 降低耦合：修改类内部逻辑不影响外部调用。

测试场景：POM 模式就是把每个页面封装为一个类，元素定位是属性，操作是方法。当 UI 改动时只需修改对应页面类。

Q9
类的命名规范是什么？属性和方法呢？
进阶
+
  • 类名：大驼峰命名法（PascalCase），所有单词首字母大写。例如：Person、LoginPage、HouseItem。
  • 属性 / 方法 / 变量名：小写下划线（snake_case），单词间用 _ 分隔。例如：user_name、add_item、free_area。
  • 魔法方法：左右各两个下划线。例如：__init__、__str__。
  • 私有属性/方法（约定）：单下划线开头表示"内部使用"，如 _internal；双下划线开头会触发名称改写，如 __secret。

遵循这些规范的代码可读性更好，也符合 PEP 8 风格指南。

Q10
下面代码会输出什么？为什么？
陷阱
+
class Cat: def __str__(self): print("被打印了") tom = Cat() print(tom)

答案：会报错 TypeError: __str__ returned non-string (type NoneType)。

原因：__str__ 方法必须 return 一个字符串，而这里用的是 print — print 函数本身返回 None。Python 在调用 print(tom) 时会自动调用 __str__，但发现返回值不是字符串就抛出 TypeError。

正确写法：

def __str__(self): return "被打印了" # 用 return，不是 print
Q11
下面这段代码哪些会调用 __init__？为什么？
陷阱
+
a = Cat # 1 b = Cat() # 2 c = b # 3 d = a() # 4

答案：只有 ② 和 ④ 会调用 __init__。

  • ① a = Cat — 不会。这是把类本身（不是对象）赋给 a，a 现在也是这个类。
  • ② b = Cat() — 会。Cat() 是创建对象，自动调用 __init__。
  • ③ c = b — 不会。只是引用传递，c 和 b 指向同一个对象。
  • ④ d = a() — 会。因为 a 已经是 Cat 类，a() 等价于 Cat()，是创建对象。

记忆要点：只有类名后加括号 () 才是创建对象，才会触发 __init__。

Q12
在自动化测试中，面向对象有什么实际应用？
场景
+

面向对象在测试领域应用非常广泛，是测试框架设计的核心思想：

  1. Page Object Model（POM）：每个页面抽象为一个类，元素是属性，操作是方法。例如 LoginPage、CartPage。
  2. 测试数据封装：把测试用户、商品等抽象为类，便于复用和参数化。
  3. 接口测试封装：每个 API 抽象为一个方法或类，封装请求构造、断言逻辑。
  4. 基类设计：定义 BasePage、BaseTestCase 等基类，子类继承复用通用方法（继承是后续课程内容）。
  5. 测试报告对象：把测试结果封装为对象，便于序列化和展示。

掌握面向对象是从"会写脚本"进阶到"会做框架"的关键能力。
