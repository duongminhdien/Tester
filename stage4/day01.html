1Python介绍

Python由吉多·范罗苏姆（Guido van Rossum，昵称"龟叔"）创建，目前主流版本为Python3。Python是一门简单易学、免费开源的编程语言。

编译型语言 vs 解释型语言

🔧 编译型语言

如C、C++，先将源代码编译成二进制可执行文件，再运行。速度快。

🐍 解释型语言

如Python，边解释边执行，从上到下逐行执行。下方代码的错误不会影响上方代码的执行。

Python在测试领域的应用

  • Python + requests → 接口自动化
  • Python + Selenium → Web自动化
  • Python + Appium → 移动端自动化（手机APP）

2环境搭建

Python环境（必须有）

安装Python解释器（Python 3.6及以上版本），安装时注意：

  • 勾选添加PATH环境变量（让程序可在任意目录执行）
  • 安装目录不要有中文，选择空目录
  • 安装后不要自己移动文件

PyCharm环境（IDE）

PyCharm是Python最好用的集成开发环境（IDE）之一，可以写代码、执行代码、查看结果。

创建项目步骤：

  1. 双击打开PyCharm
  2. Create New Project
  3. 配置代码路径和解释器路径（选择System Interpreter）
  4. 右键项目 → New → Python File → 输入文件名
  5. 书写代码（必须顶格书写）
  6. 右键 → Run 运行代码，查看控制台结果
🔧 PyCharm常用设置
File → Settings → Appearance → Theme 设置背景色；Editor → Font 设置字体和大小；Project → Project Interpreter 配置解释器。

3注释

注释是对代码进行解释和说明的文字，不会被解释器执行。作用是增强代码的可读性。

单行注释

# 这是一个单行注释 print('hello world') # 也可以写在代码后面 # 快捷键：Ctrl + /

多行注释

""" 这是三对双引号组成的多行注释 可以换行，不会被执行 """ ''' 这是三对单引号组成的多行注释 同样不会被执行 '''
⚠️ 注释注意点
注释并非越多越好，一目了然的代码无需注释。逻辑复杂的代码应先写注释再编码。不要用中文去翻译Python代码的含义。

4变量（重点）

变量的作用是用来保存数据的。变量必须先定义后使用。

定义与使用

# 定义语法：变量名 = 数据值 name = "小明" # 定义变量并赋值 print(name) # 使用变量，输出：小明 print('name') # 输出引号中的内容：name age = 18 print(age) # 输出：18

变量名命名规范

标识符规则：

  • 由字母、数字和下划线组成，不能以数字开头
  • 不能使用Python内置关键字（如 if、True、False、and、or、not）
  • 区分大小写（Name 和 name 是不同的变量）

命名规范：

  • 见名知意
  • Python主要使用下划线连接（如 my_name、student_age）
  • 大驼峰：MyName（每个单词首字母大写）
  • 小驼峰：myName（第一个单词首字母小写）
# 合法变量名示例 a = 1 # ✓ _a = 2 # ✓ num2 = 3 # ✓ my_name = "小明" # ✓ 推荐 # 非法变量名示例 # 2name ✗ 数字开头 # if ✗ 关键字 # a-b ✗ 含有减号 # !hello ✗ 含有特殊字符

6数据类型转换

将一种数据类型转换为另一种数据类型。注意：数据类型转换不会改变原数据的类型，而是生成一个新数据。

函数作用注意事项
int()转换为整型float可以转；只有整数类型的字符串才能转（如 '18'）
float()转换为浮点型int可以转；数字类型的字符串都可以转
str()转换为字符串任意类型都可以转（加引号）
# 类型转换示例 int(3.14) # 3（截断小数部分） int('12') # 12 float(18) # 18.0 float('3.14') # 3.14 str(100) # '100'

7输入与输出

输入 input()

从键盘获取数据，使用 input() 函数。

# 语法：变量 = input('提示信息') name = input('请输入你的姓名：') print(type(name), name)
💡 input() 三个特点
1. 遇到 input 会暂停执行，等待用户输入；2. 输入过程中遇到回车表示输入结束；3. 获取的内容都是字符串类型（str）。

输出 print()

print() 是Python的输出函数，将内容显示在控制台。默认 end='\n'（输出后换行）。

格式化输出

# 方法一：f-string（推荐，Python 3.6+） name = '小明' age = 18 print(f'我的名字是 {name}, 年龄 {age} 岁') # 方法二：format() print('我的名字是 {}, 年龄 {} 岁'.format(name, age)) # 方法三：字符串拼接（+） print('我的名字是 ' + name + ', 年龄 ' + str(age) + ' 岁')

转义字符

  • \n — 换行（回车）
  • \t — 制表符（Tab键）

比较运算符的结果是 bool 类型（True 或 False）。

!=不相等a != b → True

<小于a < b → False
>=大于等于a >= b → True
<=小于等于a <= b → False

逻辑运算符

符号含义规则
and逻辑与（并且）一假为假，两个条件都为True才为True
or逻辑或（或者）一真为真，只要一个条件为True就为True
not逻辑非（取反）True变False，False变True

*=乘后赋值a *= b → a = a * b
/=除后赋值a /= b → a = a / b
%=取余后赋值a %= b → a = a % b

💬面试精讲

共12道Python基础面试题，涵盖语言特性、变量、数据类型和运算符等核心知识。

Q1
Python是编译型语言还是解释型语言？有什么区别？
基础
+

Python是解释型语言。编译型语言（如C/C++）先将源代码编译成可执行文件再运行，速度快；解释型语言（如Python）由解释器逐行解释执行，开发效率高但运行速度相对较慢。Python从上到下执行，下方代码的错误不会影响上方代码的执行。

Q2
Python中变量名的命名规则是什么？
基础
+

1. 由字母、数字和下划线组成，不能以数字开头

2. 不能使用Python内置关键字（如 if、True、False、and、or、not等）

3. 区分大小写

4. 命名规范：见名知意，Python推荐使用下划线连接（如 my_name），也可以使用驼峰命名（大驼峰MyName、小驼峰myName）

Q3
描述 input() 函数的特点。
基础
+

1. 代码执行遇到 input 时会暂停，等待用户输入

2. 输入过程中遇到回车键表示输入结束

3. 使用 input 获取的内容都是字符串类型（str），如果需要数字运算，需要用 int() 或 float() 进行类型转换

Q4
Python中常见的数据类型有哪些？
基础
+

数字类型：int（整型）、float（浮点型）、bool（布尔型，True/False）

非数字类型：str（字符串）、list（列表）、tuple（元组）、dict（字典）、set（集合）

可以使用 type() 函数查看变量的数据类型。

Q5
int()、float()、str() 三个类型转换函数有什么区别？
进阶
+

int()：float可以转（截断小数）；整数类型的字符串可以转（如 '18'），小数字符串不可以转

float()：int可以转（加.0）；数字类型字符串都可以转（整数和小数字符串）

str()：任意类型都可以转换为字符串（加引号）

注意：类型转换不会改变原数据的类型，而是生成一个新数据。

Q6
Python中 / 和 // 和 % 的区别？
进阶
+

/（除法）：返回浮点数结果，如 9 / 2 = 4.5

//（求商/整除）：返回整数商，如 9 // 2 = 4

%（取余）：返回余数，如 9 % 2 = 1

应用：% 常用于判断一个数是否为偶数（num % 2 == 0）

Q7
and、or、not 三个逻辑运算符的规则？
基础
+

and（逻辑与）：一假为假。两个条件都为True，结果才为True

or（逻辑或）：一真为真。只要一个条件为True，结果就为True

not（逻辑非）：取反。True变False，False变True

Q8
Python中 == 和 = 的区别？
基础
+

= 是赋值运算符，将右边的值赋给左边的变量，如 a = 10

== 是比较运算符，判断两个值是否相等，返回 True 或 False，如 a == 10 → True

Q9
f-string 和 format() 格式化输出的区别？
进阶
+

f-string：Python 3.6+ 开始可用，在字符串前加 f 或 F，变量直接写在 {} 中，如 f"名字:{name}"，更简洁直观

format()：任意Python版本可用，字符串中用 {} 占位，变量在 format() 括号中按顺序写，如 "名字:{}".format(name)

Q10
Python中的注释有哪些？快捷键是什么？
基础
+

单行注释：以 # 开头，快捷键 Ctrl + /

多行注释：三对单引号 ''' ''' 或三对双引号 """ """

注释的作用是增强代码可读性，注释的代码不会被执行。

Q11
Python中 \n 和 \t 是什么？print 函数的 end 参数有什么用？
进阶
+

\n：换行符（回车），让后续内容从下一行开始

\t：制表符（Tab键），插入一个水平缩进

end参数：print 函数默认 end='\n'，每次输出后自动换行。可以修改 end 参数改变输出后的行为，如 print('hello', end=' ') 输出后不换行而是加空格。

Q12
为什么说Python适合做自动化测试？
高频
+

1. 简单易学：语法简洁，开发效率高，适合测试人员快速上手

2. 丰富的库支持：requests（接口自动化）、Selenium（Web自动化）、Appium（移动端自动化）、UnitTest/Pytest（测试框架）

3. 跨平台：支持 Windows、Linux、Mac 多平台运行

4. 社区活跃：大量教程和开源工具，遇到问题容易找到解决方案
