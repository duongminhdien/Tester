🗺️Stage 2 知识地图

下面是 Day 01-06 的核心知识点速查表，可作为考前复习清单：

🐧 Day 01 · Linux 基础与文件操作

  • ls查看目录；-l 详细 -a 隐藏 -h 大小
  • cd切换目录；~ 家目录 / 根 .. 上级 - 上次
  • touch/mkdir创建文件/目录；mkdir -p 多层
  • rm -rf强制递归删除；生产禁用 rm -rf /
  • cp -r / mv复制目录 / 移动或重命名
  • cat/more/grep查看文件；grep -n -i -v 选项
  • > / >>覆盖重定向 / 追加重定向
  • |管道符；前一命令输出 → 后一命令输入
  • 目录结构：/ /home /etc /usr/bin /tmp /opt /var/log
  • SSH：ifconfig 查 IP → ping 测通 → FinalShell 连接

🔧 Day 02 · 系统命令/权限/vi

  • ps -aux查看进程；kill -9 PID 强制终止
  • netstat -anptu查端口；lsof -i:端口
  • tail -f实时监控日志；测试排查 Bug 必用
  • 权限：r=4 w=2 x=1；755=rwxr-xr-x；644=rw-r--r--
  • chmod 数字法：755 目录默认 / 644 文件默认
  • tar：-z gzip .tar.gz；-j bzip2 .tar.bz2；-c 创建 -x 解压
  • vi 三模式：命令 ↔ i插入 ↔ :末行（:wq 保存退出 :q! 不保存）
  • find -name '*.txt'；ln -s 创建软链接
  • yum在线安装（自动依赖）/ rpm离线 / 源码编译
  • kill 与 kill -9 区别：SIGTERM 温柔请求 vs SIGKILL 强制

🗄️ Day 03 · 数据库基础/Navicat/SQL入门

  • 关系型：MySQL/Oracle/SQLite；NoSQL：Redis/MongoDB
  • 数据库=文件、表=Sheet、行=记录、列=字段
  • SQL分类：DQL(select) DML(insert/update/delete) DDL(create/drop/alter)
  • 连接：mysql -h IP -P 3306 -u root -p密码
  • 数据类型：int / decimal(M,N) / varchar(N) / datetime
  • 约束：primary key / auto_increment / not null / unique / default / foreign key
  • CREATE TABLE：字段名 类型 约束；INSERT INTO VALUES
  • 备份：mysqldump -uroot -p 库名 > backup.sql
  • show databases / use 库名 / show tables / desc 表名
  • 字符集建库必须 charset=utf8mb4（支持emoji）

📝 Day 04 · SQL CRUD/条件/聚合/分组/分页

  • INSERT 多行方式二 VALUES(...),(...)比方式一快 5~10 倍
  • UPDATE 必须加 WHERE！否则全表修改（生产事故 #1）
  • DELETE（可回滚）/ TRUNCATE（重置ID）/ DROP（删表结构）
  • WHERE 6种：比较 / 逻辑AND OR NOT / LIKE % _ / IN BETWEEN / IS NULL / NOT
  • 聚合函数：COUNT(*) MAX MIN SUM AVG；COUNT(字段)不统计NULL
  • GROUP BY + HAVING；HAVING 在分组后过滤，可用聚合函数
  • ORDER BY ASC/DESC；LIMIT 起点, 数量；分页公式 LIMIT (n-1)*m, m
  • 执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
  • 逻辑删除：is_delete=1 标记，不物理删除（可审计可恢复）
  • DISTINCT 去重；AS 起别名（字段/表）；SELECT * 生产不推荐

🔗 Day 05 · 联表查询/自关联/子查询

  • INNER JOIN 取交集；LEFT JOIN 左表全保留；RIGHT JOIN 右表全保留
  • ON 指定连接条件（外键关系）；可连续 JOIN 多张表
  • 自关联：同一张表别名不同的 JOIN（省市区、分类树、员工上级）
  • 子查询 4 类：标量（单值）/ 列（IN）/ 行（多列）/ 表（FROM临时表）
  • 子查询在 FROM 中必须有别名：(SELECT ...)AS temp
  • IN vs EXISTS：子查询小→IN；子查询大→EXISTS 短路效率高
  • JOIN 优先于子查询（性能更好，优化器可优化）
  • LEFT JOIN + IS NULL：查找在左表有但右表没有的记录
  • ON 在连接时过滤；WHERE 在连接后过滤；LEFT JOIN 时结果不同
  • ANY（任意一个）/ ALL（所有）/ SOME（=ANY）

🛒 Day 06 · TPShop 部署/数据库验证

  • LNMP：Linux + Nginx + MySQL + PHP
  • ifconfig 查IP；ping 测通；FinalShell 远程连接
  • tp_users：user_id/email/qq(昵称)/pay_points(积分)/user_money
  • tp_goods_category：id/name/parent_id(自关联)/level（分类树）
  • tp_order → tp_order_goods（order_id关联）
  • tp_cart：user_id/goods_id/goods_price/goods_num
  • 自关联查分类：FROM category AS parent JOIN category AS child ON child.parent_id=parent.id
  • UPDATE qq='test001' WHERE user_id=1；必须加WHERE！
  • 测试验证：操作UI后 SELECT 数据库验证数据正确落库
  • tester用SQL：验证数据 / 造测试数据 / 排查根因 / 一致性校验
