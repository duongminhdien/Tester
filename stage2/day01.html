一、Linux 操作系统介绍
01 — Linux是什么？
Linux 是一个开源、免费的操作系统，其内核由 Linus Torvalds 于1991年创建。严格来说，Linux 是操作系统的内核，常见发行版有 CentOS、Ubuntu、Debian、RedHat 等。

血缘关系：Unix → BSD → Darwin/macOS；Linux 是 Unix 精神的继承者（GNU is Not Unix）
✅ Linux 4大特点
开源免费
安全稳定
可移植性好（可安装在不同设备）
高性能

二、Linux 目录结构（重要）
03 — 核心目录说明
/ (根目录，唯一)
├── home 用户目录，~等价于/home/用户名
├── root 管理员root的专属目录
├── usr 用户软件安装目录（Unix System Resources）
├── etc 系统配置文件
├── boot 启动文件（内核）
├── bin 常用命令（ls/cd等在这里）
├── tmp 临时文件（重启后清空）
├── var 日志文件
└── opt 第三方软件安装位置
📌 关键点：Linux 只有一个根目录 /，所有目录都从根出发。~ 表示当前用户的家目录，通常是 /home/用户名（root用户是 /root）
目录全称/含义用途
/Root（根）整个文件系统的起点，唯一根
/homeHome directory普通用户的家目录所在（/home/admin）
/rootRoot's homeroot管理员专属家目录
/etcEtcetera系统和软件的配置文件（MySQL配置在这）
/usr/binUser Binary用户级别的命令（ls, grep等）
/tmpTemporary临时文件，重启后可能清空
/optOptional第三方软件安装目录（JDK, MySQL等）
三、远程连接 Linux
04 — SSH远程连接流程
要远程控制Linux服务器，需要：① 对方开启SSH服务 ② 知道IP地址和端口 ③ 使用SSH客户端连接
🔍 查看Linux的IP地址
[admin@localhost ~]$ ifconfig
ens33: inet 192.168.228.134 netmask 255.255.255.0
🏓 测试网络连通性
$ ping 192.168.228.134
64 bytes from 192.168.228.134: icmp_seq=1 ttl=64 time=0.4ms
工具类型特点
FinalShellSSH客户端国产，免费，功能丰富，SFTP文件传输
XShellSSH客户端功能强大，企业常用
连接步骤① ifconfig查IP → ② ping测连通 → ③ 客户端填IP/端口22/用户名/密码 → ④ 连接
💡 检查SSH服务是否开启：netstat -anpt | grep ssh — 如果看到LISTEN状态说明SSH服务正常运行，可以连接
Linux 命令格式 & 全部常用命令
命令格式
command [-options] [parameter]
command
命令的名称（必须有）
[-options]
可选项，可有一个或多个，也可没有
[parameter]
参数，可有一个或多个，也可没有
📌 查看帮助：command --help（简洁）或 man command（详细，按Q退出）
3.1 ★★★ ls — 查看目录内容
格式：ls [-lah] [文件或目录]
-l
列表形式显示详细信息
-a
显示所有文件（含隐藏文件）
-h
显示文件大小（须与-l合用）
admin@localhost:~
[admin@localhost ~]$ ls# 列出当前目录文件
公共 模板 视频 图片 文档 下载 音乐 桌面
[admin@localhost ~]$ ls -l# 详细信息
drwxr-xr-x. 2 admin admin 6 5月 16 2020 公共
[admin@localhost ~]$ ls -lha# 详细+隐藏+大小
[admin@localhost ~]$ ls -lha /usr/bin# 查看指定目录
[admin@localhost ~]$ ls *.txt# 通配符：所有.txt文件
123.txt 1.txt 23.txt abc.txt ab.txt
[admin@localhost ~]$ ls /bin/*.sh# /bin目录下所有.sh文件
通配符说明：* 匹配0到多个任意字符；? 匹配单个任意字符；[abcd] 匹配括号内任意一个字符；[a-z] 匹配a到z范围内任意一个字符
3.2 ★★★ cd — 切换目录
格式：cd [目录路径]
命令作用示例
cd回到家目录（等同于cd ~）cd
cd ~回到家目录（/home/用户名）cd ~
cd /去根目录cd /
cd ..返回上一层目录cd ..
cd -返回上一次所在目录cd -
cd /etc/abrt绝对路径（/开头，唯一确定）cd /etc/abrt
cd usr/bin相对路径（当前位置出发）当前在/时用cd usr/bin
🔴 绝对路径 vs 相对路径：
绝对路径：必须以 / 或 ~ 开头，是唯一确定的路径（如 /etc/kernel）
相对路径：不以 / 或 ~ 开头，从当前位置出发（如 usr/bin，效果随当前位置变化）
3.3 touch · 3.4 ★★★ mkdir — 创建文件/目录
touch — 创建文件
$ touch 1.txt 2.txt
# 同时创建多个文件
# 文件已存在→更新修改时间
创建的是普通文件（不是文件夹）
mkdir — 创建目录
$ mkdir mike
# 当前路径下创建mike
$ mkdir -p a/b/c
# 创建多层嵌套目录
目录已存在→报错；用-p可创建多层
3.5 ★★★ rm — 删除文件或目录
格式：rm [-irf] 目录名或文件名
选项含义说明
-i交互式删除删除前询问确认（默认选项），推荐使用
-f强制删除忽略不存在的文件，不提示确认
-r递归删除删除目录及目录下所有内容（必须加）
$ rm -r mike/# 删除mike目录及其下所有内容
$ rm -rf a.txt# 强制删除，不提示
$ rm -rf test*# 删除所有test开头的目录/文件
⚠️ 重要警告：rm 删除后无法恢复！建议在 rm 命令后加 -i 参数，养成删除前确认的好习惯。生产环境禁止 rm -rf /！
3.6 ★★★ cp · 3.7 ★★★ mv — 复制/移动
cp — 复制
格式：cp [-rif] 源 目标
$ cp 1.txt abc.txt
# 复制文件（改名）
$ cp -r mike tom
# 复制目录（必须-r）
mv — 移动/重命名
格式：mv [-if] 源 目标
$ mv a.txt mike/
# 移动到mike目录
$ mv tom.txt rock.txt
# 重命名文件
mv 的双重作用：① 目标是目录 → 移动文件；② 目标是新文件名 → 重命名文件
3.8 查看文件内容 — cat · more · grep
命令适用场景常用选项快捷键
cat 文件内容少的文件，全部显示-n 显示行号；-b 非空行行号—
more 文件内容多的文件，分页查看—空格=下一页；b=上一页；q=退出
grep '关键字' 文件搜索文件中包含关键字的行-n 显示行号；-i 忽略大小写；-v 反转（不含）—
$ cat -n /etc/hosts# 带行号查看
$ more /var/log/messages# 分页查看大文件
$ grep -n 'root' /etc/passwd# 搜索含root的行并显示行号
1:root:x:0:0:root:/root:/bin/bash
$ grep -v '#' /etc/hosts# 排除含#的行
3.9 重定向 > >> · 3.10 ★★ 管道符 | · 3.11 其他命令
符号/命令作用示例
>输出重定向（覆盖写入）ls -l > result.txt
>>输出重定向（追加写入）cat 1.txt >> 2.txt
|（管道）将前一个命令的输出作为后一个命令的输入ls -l | more
pwd显示当前路径pwd
clear清屏（Ctrl+L也可以）clear
which查看命令的安装路径which ls
$ cat 1.txt > 2.txt# 1.txt内容覆盖写入2.txt
$ cat 1.txt 2.txt > 3.txt# 合并1.txt和2.txt到3.txt
$ ls /usr/bin | more# 分页查看/usr/bin内容
$ ls /usr/bin | grep '^au'# 查找au开头的命令
$ ls /etc | grep 'conf$'# /etc下以conf结尾的文件

Q1. 什么是操作系统？
操作系统（OS）是管理计算机硬件和软件资源的系统软件，为用户和应用程序提供运行环境。它负责进程管理、内存管理、文件系统、设备驱动等核心功能。Linux、Windows、macOS都是常见的操作系统。
