## 📋 Project Context — Hệ thống học tập QA/Testing (Cập nhật)

---

### Tổng quan dự án

Xây dựng **hệ thống học tập offline hoàn chỉnh** dưới dạng các file HTML độc lập, dành cho người học tiếng Trung đang theo khóa học kiểm thử phần mềm (软件测试). Người dùng là **BA và Product Owner người Việt** học QA để chuyển ngành hoặc mở rộng kỹ năng.

---

### Kiến trúc file

```
📁 outputs/
├── index.html                  ← Trang chủ: sidebar điều hướng, progress tracking, export/import JSON
├── template_day.html           ← Template mẫu cho các ngày (chưa dùng trực tiếp)
├── 📁 stage1/                  ← Giai đoạn 1: Kiến thức cơ bản testing
│   ├── day01.html
│   ├── day02.html
│   ├── day03.html
│   ├── day04.html
```

**Cách mở:** Mở `index.html` bằng trình duyệt → click bài học trong sidebar → nội dung load trong iframe bên phải.

### Design system

**Font:** `'Source Han Sans SC', 'Noto Sans SC', sans-serif` — load từ CDN jsdelivr + Google Fonts

**Màu chủ đề theo ngày:**
- Day 01: `#dc2626` (đỏ)
- Day 02: `#7c3aed` (tím)
- Day 03: `#0891b2` (teal)
- Day 04: `#16a34a` (xanh lá)
- Day 05: `#ea580c` (cam)
- Linux Day 01: `#1e293b` (đen slate)
- *(Các ngày mới: chọn màu chưa dùng, khai báo `--day` trong `:root`)*

**UI components tái sử dụng:**
- Terminal block: `background:#1e2030`, syntax highlighting màu
- Card hover, info/tip/danger/ok boxes
- Accordion interview questions (`.iq`, `.iq-hdr`, `.iq-body`)
- Quiz engine: sel/ok/no state, auto-grade, postMessage score về parent
- Dot navigation progress indicator (`#dots`)
- Checkbox completion tracking (`.ci`, `.cp()`)
- Tab navigation (`.dn`, `.ts`, `.t`, `.t.a`)

**Responsive:** Tất cả file có `@media(max-width:640px)` — grid 3-cột → 1-cột, padding nhỏ hơn, tab font nhỏ hơn.

**Line-height:** 1.7–1.75 | **Letter-spacing:** 0.01em

### Hệ thống lưu tiến độ (Progress Store)

**Lưu tại:** `localStorage` key `qa_progress_v2`

**Cấu trúc JSON:**
```json
{
  "version": 2,
  "createdAt": "...",
  "lastUpdated": "...",
  "completed": {
    "s1d1": {
      "completedAt": "2025-05-18T10:30:00Z",
      "timeSpentMin": 45,
      "quizScore": 10,
      "quizTotal": 12
    }
  },
  "quizHistory": {
    "s1d1": [
      { "score": 8, "total": 12, "pct": 67, "date": "..." },
      { "score": 10, "total": 12, "pct": 83, "date": "..." }
    ]
  }
}
```

**Các tính năng:**
- Nhấn **✓ 标记完成** → lưu ngày hoàn thành + thời gian học (phút) + điểm quiz gần nhất
- Submit quiz → gửi `postMessage({type:'qa_quiz_result', score, total})` lên `window.parent` (index.html)
- Index.html lắng nghe message → lưu vào `quizHistory`, giữ tối đa 10 lần gần nhất
- Nút **⬇** trên topbar → export file `qa_progress_YYYY-MM-DD.json`
- Nút **⬆** trên topbar → import file JSON để khôi phục tiến độ (chuyển máy)
- Migration tự động từ key cũ `qa_completed` (array) sang format v2

**Sidebar mobile:** Có overlay tối + nút ✕ + tự đóng khi chọn bài.

### Quy tắc coding

- **Không framework** — thuần HTML/CSS/JS, không jQuery, không React
- **Self-contained** — mỗi file hoàn toàn độc lập, không cần server
- **CSS variables** — tất cả màu dùng `--day`, `--bg`, `--border` etc. trong `:root`
- **Space Mono** cho code/terminal; **Source Han Sans SC** cho nội dung
- **Số Quiz tối thiểu:** 15 câu mỗi ngày (Day03 có 18)
- **Số Phỏng vấn tối thiểu:** 12 câu mỗi ngày
- Mỗi câu quiz có `exp` giải thích chi tiết
- Badge level phỏng vấn: `lv-b`=🟢基础, `lv-m`=🟡进阶, `lv-h`=🔴陷阱/场景
- **postMessage bắt buộc** trong hàm `sub()` của quiz:
  ```js
  try { window.parent.postMessage({type:'qa_quiz_result', score, total:QS.length}, '*'); } catch(e) {}
  ```
- **@media(max-width:640px) bắt buộc** ở cuối `<style>` mỗi file

### Cách thêm bài học mới

**Bước 1:** Tạo file HTML theo template (5 tab, màu mới, postMessage trong quiz)

**Bước 2:** Thêm entry vào `CURRICULUM` trong `index.html`:
```js
{
  id: 's2d2',           // stage_số + d + số thứ tự
  day: 'Day 06',
  title: 'Postman实战入门',
  file: 'stage2/day06.html',
  tags: 'Collection·变量·断言',
  practice: 3,
  qa: 8,
  status: 'locked'      // hoặc 'available' để mở ngay
}
```

**Đặt file đúng chỗ:** `stage1/`, `stage2/`... tương ứng với `file:` trong CURRICULUM.

### Workflow làm việc

1. Người dùng upload tài liệu (PDF/XMind/Excel/RAR) của ngày học
2. AI đọc toàn bộ, extract nội dung theo curriculum thực tế
3. Tạo file HTML hoàn chỉnh: đúng màu, đúng template, có postMessage, có @media
4. Người dùng tải file về, đặt vào thư mục `stage_/` tương ứng
5. Không cần sửa gì thêm — mở `index.html` là dùng được

---

### Lưu ý quan trọng khi tạo file mới

- Giữ **nhất quán** font, cấu trúc 5 tab, quiz engine giữa tất cả file
- **Không dùng `min-width` cứng** lớn hơn 300px trong inline style
- **Không dùng `grid-template-columns: repeat(N, 1fr)`** cứng trong inline style — dùng `repeat(auto-fit, minmax(..., 1fr))`
- Terminal blocks: `background:#1e2030`, text `#a6accd`
- Màu mỗi ngày **không trùng** với ngày đã có
- File RAR nếu có → giải nén bằng `unrar`, đọc source code rồi tích hợp
